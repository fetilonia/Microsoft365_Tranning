## L2 · 구성 프로필 · 앱 배포 — 설정 · 인증서 · Wi-Fi · 업무 앱

- 설정(Control Plane): Windows 구성 프로필의 설정 카탈로그 | Win32 앱 요구 사항 · 설치 명령 · 검색 규칙 · 그룹 할당
- 강제(Enforcement): Windows MDM 채널이 설정 적용 | Intune Management Extension이 할당된 Win32 앱 설치·검색
- 증적(Evidence): 구성 프로필 기기·설정별 상태 및 충돌 | 앱 기기 설치 상태와 설치·검색 오류
- 메뉴(Admin Center): Intune 관리 센터 > Devices > Manage devices > Configuration | Apps > Windows [확인 필요: 현재 포털 메뉴]
- 라이선스(License): Intune 관리 및 대상 Windows 기기·사용자의 라이선스 [확인 필요: 제품 조합과 배포 요건]

### L3 · 0 · 기능 상태 전이 — 미할당 → 구성 → 적용·설치

> 교육 포인트: 구성 프로필과 Win32 앱은 각각 별도의 대상·상태를 가지므로 한쪽 성공으로 다른 쪽 성공을 추정하지 않습니다.
> 출처: https://learn.microsoft.com/en-us/intune/device-configuration/settings-catalog/
> 출처: https://learn.microsoft.com/en-us/intune/app-management/deployment/win32

#### L4 · ⓪ 비활성 — 설정과 앱이 배포되지 않았다

1. [시작] 관리 기기에 사용자가 로그인한다
   - 주체: 사용자
   - 데이터: Windows 관리 기기
   - 해설: 기기 등록 자체가 새 설정과 앱 배포를 의미하지는 않습니다
2. [처리] 선택한 설정 프로필이 대상에 없다
   - 주체: Intune
   - 데이터: 프로필 할당 없음
   - 해설: 이 프로필이 제공하는 설정은 배포되지 않습니다
3. [처리] 업무 앱도 대상에 할당되지 않았다
   - 주체: Intune
   - 데이터: Win32 앱 할당 없음
   - 해설: 이 할당을 통해 자동 설치가 시작되지는 않습니다
4. [끝] 관리자가 설정과 설치 요구를 구분한다
   - 주체: 관리자
   - 데이터: 프로필과 앱의 독립 배포 계획
   - 해설: 기존 설정이나 수동 설치 앱의 유무는 별도로 확인합니다

#### L4 · ① 구성 — Windows 설정과 필수 앱을 할당한다

1. [시작] 관리자가 대상 기기와 설정 요구를 확인한다
   - 주체: 관리자
   - 위치: Intune 관리 센터
   - 데이터: 지원 Windows 플랫폼 · 테스트 그룹
   - 해설: 테스트 대상과 플랫폼을 먼저 정합니다
2. [처리] 설정 카탈로그 프로필을 만든다
   - 주체: 관리자
   - 위치: Devices > Manage devices > Configuration > Create [확인 필요: 메뉴]
   - 데이터: Windows 10 and later · Settings catalog
   - 해설: 선택한 설정을 포함하는 구성 프로필을 만듭니다
3. [처리] 관리할 설정과 값을 선택한다
   - 주체: 관리자
   - 위치: 구성 프로필 > Configuration settings
   - 데이터: 선택한 카탈로그 설정 · 값 · 사용자/기기 범위
   - 해설: 같은 설정의 다른 정책과 충돌하지 않는지 확인합니다
4. [처리] 프로필을 테스트 그룹에 할당한다
   - 주체: 관리자
   - 위치: 프로필 > Assignments
   - 데이터: 포함 · 제외 그룹 및 필터 [확인 필요: 해당 배포 방식]
   - 해설: 정책을 받을 대상과 제외 대상을 지정합니다
5. [처리] Win32 앱 패키지와 설치 정보를 등록한다
   - 주체: 관리자
   - 위치: Apps > Windows > Add
   - 데이터: 패키지 · 설치 명령 · 요구 사항 · 검색 규칙
   - 해설: 앱이 설치 가능한 조건과 설치 성공을 판단하는 방법을 정의합니다
6. [처리] 앱을 필수로 그룹에 할당한다
   - 주체: 관리자
   - 위치: 앱 > Assignments
   - 데이터: Required 할당 및 대상 그룹
   - 해설: 필수 앱의 대상과 프로필 대상을 각각 확인합니다
7. [끝] 설정과 앱의 할당을 저장한다
   - 주체: 관리자
   - 위치: Intune 관리 센터
   - 데이터: 프로필 및 앱의 별도 할당
   - 해설: 이후 기기 동기화와 설치 상태를 관찰합니다

#### L4 · ② 활성 — 기기가 설정과 앱을 받는다

1. [시작] 대상 Windows 기기가 Intune과 동기화한다
   - 주체: 디바이스
   - 데이터: 관리 기기 ID와 대상 멤버십
   - 해설: 기기는 할당된 정책을 확인합니다
2. [처리] 구성 프로필의 설정을 수신한다
   - 주체: 디바이스
   - 데이터: 플랫폼에 맞는 설정과 값
   - 해설: Windows MDM 관리 채널이 설정을 전달합니다
3. [처리] Windows가 설정을 적용하고 상태를 보고한다
   - 주체: 디바이스
   - 데이터: 설정별 성공 · 오류 · 충돌 상태
   - 해설: 설정의 기기 보고 상태를 따로 확인할 수 있습니다
4. [처리] Intune Management Extension이 앱 할당을 확인한다
   - 주체: Intune Management Extension
   - 데이터: Win32 앱 대상 · 요구 사항
   - 해설: 해당 기기에 앱 설치가 필요한지 확인합니다
5. [처리] 앱 설치 명령과 검색 규칙을 실행한다
   - 주체: Intune Management Extension
   - 데이터: 설치 결과 · 검색 규칙 결과
   - 해설: 검색 결과가 설치 상태 판단에 사용됩니다
6. [끝] 관리자가 두 보고서를 비교한다
   - 주체: 관리자
   - 위치: 구성 프로필 > View report · Apps > 앱 설치 상태
   - 데이터: 프로필 상태와 앱 설치 상태
   - 해설: 설정과 앱 중 어느 경로에 문제가 있는지 구분합니다

### L3 · A · 핵심 동작 — 설정 충돌과 앱 설치 오류

> 교육 포인트: 동일 설정의 상충 값은 구성 보고서에서 확인하고, Win32 앱 설치와 검색은 별도 보고서에서 확인합니다.
> 주의: 앱 설치 오류 코드와 설정 충돌의 최종 동작은 설정·OS 버전별로 [확인 필요: 기능·플랫폼·정책 모드별 동작을 최신 Microsoft Learn 및 격리된 테스트 테넌트에서 재현해 확인]입니다.
> 출처: https://learn.microsoft.com/en-us/intune/device-configuration/settings-catalog/
> 출처: https://learn.microsoft.com/en-us/intune/app-management/deployment/win32

#### L4 · ▶ 프로필과 필수 앱 배포 — 할당과 두 결과를 확인한다

1. [시작] 관리자가 Windows 테스트 그룹에 프로필과 앱을 할당한다
   - 주체: 관리자
   - 위치: Configuration · Apps > Assignments
   - 해설: 두 할당은 서로 독립입니다
2. [판단] 기기가 두 할당의 대상인가?
   - 주체: Intune
   - 데이터: 그룹 멤버십 · 포함/제외
   - 해설: 이 예제는 두 할당 모두에 포함된 기기를 전제로 합니다
   - 대상 → 3
   - 대상 아님 → [끝] 대상 제외 — 해당 할당의 그룹과 필터 확인
3. [판단] 구성 프로필에 동일 설정의 충돌이 있는가?
   - 주체: Intune
   - 데이터: 동일 설정에 지정된 서로 다른 값
   - 해설: 다른 프로필이 같은 설정을 다른 값으로 구성했는지 확인합니다
   - 없음 → 4
   - 있음 → [차단] 설정 충돌 — 프로필의 설정별 상태 확인
4. [처리] 기기가 프로필 설정을 적용하고 보고한다
   - 주체: 디바이스
   - 위치: Configuration > 프로필 > View report
   - 해설: 프로필 성공은 앱 성공을 보장하지 않습니다
5. [판단] Win32 앱 설치와 검색이 성공했는가?
   - 주체: Intune Management Extension
   - 데이터: 설치 명령 결과 · 검색 규칙
   - 해설: 앱 보고서에서 설치와 검색 문제를 구분합니다
   - 성공 → 6
   - 실패 → [차단] 앱 설치 또는 검색 실패 — 요구 사항과 로그 확인
6. [끝] 프로필과 앱 상태가 각각 성공으로 보고된다
   - 주체: 관리자
   - 위치: 구성 프로필 보고서 · 앱 설치 보고서
   - 데이터: 기기별 설정 및 앱 설치 상태
   - 해설: 두 보고서를 함께 확인해 배포를 마칩니다
- 시나리오: 대상 ▸ 없음 ▸ 성공 :: 설정과 필수 앱이 각각 적용되어 보고
- 시나리오: 대상 아님 :: 할당 대상이 아니어서 해당 배포 미적용
- 시나리오: 대상 ▸ 있음 :: 서로 다른 값이 충돌해 설정 보고서 점검
- 시나리오: 대상 ▸ 없음 ▸ 실패 :: 설정은 적용됐지만 앱 설치 또는 검색 실패
