## L2 · 기기 등록 — Autopilot · 회사 포털

- 설정(Control Plane): Windows Autopilot 기기 등록과 배포 프로필 | 사용자 기반 Entra 조인 · MDM 자동 등록 범위 | 등록 제한
- 강제(Enforcement): Windows OOBE에서 프로필을 받아 조직 로그인 · Entra 조인 · MDM 등록
- 증적(Evidence): Autopilot 기기 프로필 할당 상태 | Intune 관리 디바이스와 등록 실패 보고서 | Entra 기기 조인 상태
- 메뉴(Admin Center): Intune 관리 센터 > Devices > Windows > Windows enrollment > Windows Autopilot deployment profiles [확인 필요: 현재 포털 메뉴]
- 라이선스(License): 사용자 기반 배포에 적용되는 Windows · Intune · Entra 라이선스와 사용자 할당 [확인 필요: 고객 SKU 및 자동 등록 조건]

### L3 · 0 · 기능 상태 전이 — 미등록 → 배포 준비 → 관리 기기 등록

> 교육 포인트: Autopilot 서비스에 기기를 등록하는 것과 Intune MDM에 기기를 등록하는 것은 다른 단계입니다.
> 주의: 이 예제는 Windows 회사 소유 기기의 사용자 기반 Entra 조인입니다. 회사 포털을 통한 BYOD 등록과 하이브리드 조인은 별도로 전제와 제한을 확인합니다.
> 출처: https://learn.microsoft.com/en-us/autopilot/user-driven
> 출처: https://learn.microsoft.com/en-us/intune/device-enrollment/guide

#### L4 · ⓪ 비활성 — Autopilot 준비가 없는 회사 PC

1. [시작] 사용자가 새 Windows 기기를 켠다
   - 주체: 사용자
   - 데이터: 공장 초기 상태의 회사 PC
   - 해설: 기기에는 아직 이 예제의 조직 배포 준비가 없습니다
2. [처리] OOBE가 네트워크와 초기 설정을 요청한다
   - 주체: 디바이스
   - 위치: Windows OOBE
   - 해설: 인터넷 연결이 있어야 배포 서비스를 확인할 수 있습니다
3. [처리] 이 기기에 할당된 Autopilot 프로필이 없다
   - 주체: Windows Autopilot
   - 데이터: 기기 식별 및 프로필 할당 상태
   - 해설: 이 예제의 조직별 OOBE 구성이 자동으로 적용되지 않습니다
4. [끝] 관리자는 등록과 정책 배포를 별도로 준비한다
   - 주체: 관리자
   - 데이터: Autopilot 미구성은 다른 등록 방법도 불가능하다는 뜻이 아님
   - 해설: 관리 대상 여부는 별도 등록 방법과 설정에 달려 있습니다

#### L4 · ① 구성 — 사용자 기반 배포를 준비한다

1. [시작] 관리자가 Intune 등록 전제 조건을 확인한다
   - 주체: 관리자
   - 위치: Intune 관리 센터 · Entra 관리 센터
   - 데이터: 사용자 라이선스, Entra 조인 권한 및 MDM 자동 등록 범위 [확인 필요: 테넌트별 조건]
   - 해설: 조인과 자동 등록은 서로 다른 선행 조건을 가집니다
2. [처리] 기기를 Windows Autopilot에 등록한다
   - 주체: 관리자
   - 위치: Intune 관리 센터 > Devices > Windows > Windows enrollment > Devices [확인 필요: 메뉴]
   - 데이터: 제조사·파트너 등록 또는 하드웨어 식별자 가져오기
   - 해설: Autopilot이 배포할 기기를 식별할 수 있도록 준비합니다
3. [처리] 기기를 대상 Entra 그룹에 포함한다
   - 주체: 관리자
   - 위치: Entra 관리 센터 > Groups
   - 데이터: 정적 또는 동적 기기 그룹의 멤버십
   - 해설: 기기 그룹은 프로필 할당의 대상입니다
4. [처리] 사용자 기반 배포 프로필을 만든다
   - 주체: 관리자
   - 위치: Intune 관리 센터 > Windows Autopilot deployment profiles > Create profile [확인 필요: 메뉴]
   - 데이터: 사용자 기반 모드 · Microsoft Entra join · OOBE 옵션
   - 해설: 사용자 로그인 후 조인과 등록을 진행하도록 지정합니다
5. [처리] 프로필을 기기 그룹에 할당한다
   - 주체: 관리자
   - 위치: 배포 프로필 > Assignments
   - 데이터: 포함 대상 및 프로필 할당 상태
   - 해설: 그룹 멤버십과 서비스 반영 후 대상 기기에 프로필이 할당됩니다
6. [처리] 등록 제한과 등록 상태 페이지를 검토한다
   - 주체: 관리자
   - 위치: Intune 관리 센터 > Devices > Enrollment [확인 필요: 메뉴]
   - 데이터: 플랫폼·소유권 제한 및 ESP 선택 구성
   - 해설: 제한과 필수 구성 대기가 실제 배포에 미치는 영향을 확인합니다
7. [끝] 대상 기기의 프로필 할당 상태를 확인한다
   - 주체: 관리자
   - 위치: Windows Autopilot devices
   - 데이터: 기기 ID · 프로필 할당 상태
   - 해설: 기기가 준비됐는지 확인한 뒤 사용자 배포를 시작합니다

#### L4 · ② 활성 — 프로필을 받은 PC가 조직에 등록된다

1. [시작] 사용자가 기기를 켜고 인터넷에 연결한다
   - 주체: 사용자
   - 위치: Windows OOBE
   - 해설: 새 기기가 배포 프로필을 검색합니다
2. [처리] Autopilot 프로필을 다운로드한다
   - 주체: 디바이스
   - 데이터: 할당된 사용자 기반 배포 프로필
   - 해설: 프로필의 OOBE 설정이 적용됩니다
3. [처리] 사용자가 조직 계정으로 로그인한다
   - 주체: 사용자
   - 위치: 조직 로그인 화면
   - 해설: 사용자 신원과 기기 조인 권한을 확인합니다
4. [처리] 기기가 Microsoft Entra에 조인한다
   - 주체: 디바이스
   - 데이터: Entra 기기 개체와 조인 상태
   - 해설: 이 경로에서 기기 신원을 만듭니다
5. [처리] 기기가 Intune MDM에 자동 등록한다
   - 주체: 디바이스
   - 데이터: MDM 자동 등록 범위와 등록 결과
   - 해설: Entra 조인 이후 관리 채널이 설정됩니다
6. [처리] 구성된 경우 등록 상태 페이지가 작업을 표시한다
   - 주체: 디바이스
   - 위치: Enrollment Status Page
   - 데이터: 배포 대상 구성과 설치 상태
   - 해설: 선택된 설정에 따라 사용자에게 준비 상태가 보입니다
7. [끝] 관리자가 기기 등록 결과를 확인한다
   - 주체: 관리자
   - 위치: Intune 관리 센터 > Devices > All devices
   - 데이터: 관리 기기 목록 · 등록 상태
   - 해설: Autopilot 할당과 MDM 등록 결과를 각각 확인합니다

### L3 · A · 핵심 동작 — 사용자 기반 배포의 조건별 결과

> 교육 포인트: 프로필 할당 성공, 조인 성공, MDM 등록 성공은 하나의 동일한 결과가 아닙니다.
> 주의: 사용자 라이선스, 등록 제한 및 조인 권한 중 어떤 조건이 실패했는지 등록 진단에서 확인합니다. 오류 코드와 표현은 [확인 필요: 실제 SKU별 사용 권한과 대상 사용자 조건을 Microsoft Learn 서비스 설명·고객 계약 및 할당된 라이선스에서 대조]입니다.
> 출처: https://learn.microsoft.com/en-us/autopilot/user-driven
> 출처: https://learn.microsoft.com/en-us/intune/device-enrollment/guide

#### L4 · 회사 PC 등록 — 프로필과 등록 조건을 검사한다

1. [시작] 사용자가 회사 PC를 네트워크에 연결한다
   - 주체: 사용자
   - 위치: Windows OOBE
   - 해설: 사용자 기반 Autopilot 배포를 시작합니다
2. [판단] 기기에 배포 프로필이 할당됐는가?
   - 주체: Windows Autopilot
   - 데이터: 기기 식별자와 프로필 할당 상태
   - 해설: 대상 그룹 및 프로필 반영 여부를 확인합니다
   - 할당됨 → 3
   - 미할당 → [차단] 프로필 미할당 — 기기 식별과 대상 그룹을 점검
3. [처리] 프로필을 받고 조직 계정으로 로그인한다
   - 주체: 사용자
   - 위치: OOBE 조직 로그인
   - 데이터: 사용자 기반 Entra 조인 프로필
   - 해설: 조직용 배포 흐름이 시작됩니다
4. [판단] 사용자와 기기가 조인·등록 요건을 만족하는가?
   - 주체: Intune · Entra ID
   - 데이터: 라이선스 · 조인 권한 · MDM 범위 · 등록 제한
   - 해설: 조인 및 등록 요건을 각각 평가합니다
   - 충족 → 5
   - 미충족 → [차단] 조인 또는 등록 실패 — 해당 서비스의 오류와 전제 조건 확인
5. [처리] Entra 조인 후 Intune MDM 등록을 진행한다
   - 주체: 디바이스
   - 위치: Windows OOBE · Intune 등록 서비스
   - 해설: 기기 신원과 관리 등록이 순서대로 만들어집니다
6. [끝] 관리 기기 및 배포 상태를 확인한다
   - 주체: 관리자
   - 위치: Intune 관리 센터 > Devices > All devices
   - 데이터: Autopilot 프로필 상태 · 관리 기기 등록 결과
   - 해설: 두 서비스의 결과를 대조해 완료를 확인합니다
- 시나리오: 할당됨 ▸ 충족 :: 프로필과 등록 조건을 충족해 관리 기기 등록
- 시나리오: 미할당 :: 프로필 미할당으로 기기와 대상 그룹 점검
- 시나리오: 할당됨 ▸ 미충족 :: 등록 조건 미충족으로 조인·등록 단계 진단
