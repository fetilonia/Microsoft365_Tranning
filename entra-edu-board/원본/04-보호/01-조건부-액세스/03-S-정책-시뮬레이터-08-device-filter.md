#### 그룹 · device-filter · 디바이스 필터
- 섹션: 조건
- 선택: 다중
- 위치: 보호 › 조건부 액세스 › 정책 › 새 정책 › 조건 › 디바이스 필터(Filter for devices) [확인 필요: 한글 UI 명칭]
- 소개: 디바이스 속성 규칙식에 맞는 디바이스를 정책에 포함하거나 제외합니다.
- 평가: Entra ID가 디바이스 인증으로 Entra에 등록된 디바이스 개체의 속성을 읽어 규칙식과 대조합니다. 미등록 디바이스는 모든 속성이 null로 간주되어 양수 연산자는 일치하지 않습니다.
- 노드 제목: 디바이스 필터 일치?
- 노드 보조: 디바이스 속성 규칙식 평가(등록 여부에 따라 다름)
- 해설: Entra ID가 등록된 디바이스 속성으로 규칙식을 평가하며, 미등록 디바이스는 속성이 null이라 연산자 종류가 결과를 가릅니다.
- 주체: Entra ID
- 데이터: 디바이스 개체 속성(deviceOwnership·trustType·isCompliant·extensionAttribute1-15 등)과 규칙식(≤3072자)
- 출처: https://learn.microsoft.com/en-us/entra/identity/conditional-access/concept-condition-filters-for-devices;https://learn.microsoft.com/en-us/entra/identity/conditional-access/concept-conditional-access-conditions

##### 옵션 · df-include · 규칙에 일치하는 디바이스만 포함 (예: 개인 소유 디바이스)
- 소개: 규칙에 맞는 디바이스에만 정책을 적용합니다.
- 위치: 정책 › 조건 › 디바이스 필터 › 구성 예 › 규칙에 일치하는 디바이스: 필터링된 디바이스 포함 [확인 필요: 한글 UI 명칭] — Graph mode: include
- 동작: 규칙식(예: device.deviceOwnership -eq "Personal")에 맞는 디바이스만 정책 범위입니다. 연산자는 Equals·StartsWith·Contains·In 등과 부정형이 있습니다.
- 매칭: 등록된 디바이스의 속성이 규칙식을 만족하면 일치입니다. 양수 연산자는 미등록 디바이스에 적용되지 않고, 부정 연산자는 미등록에도 적용됩니다.
- 미충족 시: 규칙에 맞지 않거나(양수 연산자의 미등록 디바이스 포함) 이 조건이 불일치라 정책이 적용되지 않습니다.
- 지원 주체: 사용자, 에이전트(에이전트 사용자 계정은 엔드포인트에서 시작된 세션일 때만)
- 제약·주의: extensionAttribute는 Intune 관리·준수·하이브리드 조인 디바이스일 때만 값이 보입니다. 시스템 정의 속성 1개 이상 권장. 디바이스 상태 조건과는 함께 쓸 수 없습니다.
- 로그: 조건부 액세스 탭 정책 세부 정보에서 필터 일치 여부와 정책 결과를 확인합니다.

##### 옵션 · df-exclude · 규칙에 일치하는 디바이스 제외 (예: 특권 관리 워크스테이션)
- 소개: 규칙에 맞는 디바이스는 정책에서 빼 예외를 둡니다.
- 위치: 정책 › 조건 › 디바이스 필터 › 구성 예 › 규칙에 일치하는 디바이스: 정책에서 필터링된 디바이스 제외 [확인 필요: 한글 UI 명칭] — Graph mode: exclude
- 동작: 예: 관리자가 Azure 관리 API에 접근할 때 device.extensionAttribute1 -eq "SAW"(특권 관리 워크스테이션)인 디바이스를 제외하고 나머지는 차단하면 SAW에서만 접근됩니다.
- 매칭: 등록 디바이스가 규칙에 맞으면 제외 일치(= 정책 미적용). 양수 연산자에서 미등록 디바이스는 필터가 적용되지 않아 제외되지 않고 정책(예: 차단)이 적용됩니다.
- 미충족 시: 규칙에 맞지 않으면 제외되지 않아 정책이 적용됩니다.
- 지원 주체: 사용자, 에이전트(에이전트 사용자 계정은 엔드포인트에서 시작된 세션일 때만)
- 제약·주의: 같은 SAW 디바이스에도 준수 디바이스·MFA 정책을 따로 두는 2정책 구성이 문서 예시입니다. 부정 연산자와 미등록 디바이스 동작이 반대이니 report-only로 확인하세요.
- 로그: 제외 디바이스는 해당 정책이 '적용 안 됨'으로, 비제외 디바이스는 차단 결과로 로그에 남습니다.
