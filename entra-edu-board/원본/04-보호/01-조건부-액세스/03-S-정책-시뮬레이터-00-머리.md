### L3 · S · 정책 시뮬레이터 — 옵션을 고르면 평가 흐름이 바뀐다

- 설명: ① 할당 → ② 대상 리소스 → ③ 조건 → ④ 허용 컨트롤 → ⑤ 세션 컨트롤 → ⑥ 정책 상태를 직접 고르고, 아래 ‘테스트 로그인’이 그 정책에 어떻게 평가되는지 흐름으로 확인합니다.
- 프리셋: 모든 사용자 MFA :: 가장 기본적인 정책. 비상 계정만 제외 :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-all;grant=gc-mfa :: principal=member-in;resource=t-app;mfa=none :: 인증
- 프리셋: 관리자 피싱 방지 MFA :: 디렉터리 역할 관리자에게 인증 강도를 요구 :: identity=u-roles;identity-exclude=x-breakglass;resource=r-apps-all;grant=gc-strength;sub.gc-strength=phish :: principal=admin;resource=t-app;mfa=mfa;reg=phish :: 인증
- 프리셋: 준수 기기만 허용 :: 선택한 앱은 Intune 준수 기기에서만 :: identity=u-groups;identity-exclude=x-breakglass;resource=r-apps-selected;grant=gc-compliant :: principal=member-in;resource=t-app;device=personal :: 기기 · 앱
- 프리셋: 신뢰 위치 밖에서만 MFA :: 신뢰 위치가 아니면 MFA — 위치 조건 포함/제외 :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-all;loc=l-any,l-ex-trusted;grant=gc-mfa :: principal=member-in;location=other;mfa=none :: 네트워크 · 위치
- 프리셋: 규격 네트워크(GSA) 밖 차단 :: Global Secure Access가 평가하는 규격 네트워크만 허용 :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-selected;loc=l-any,l-ex-compliant;grant-mode=g-block :: principal=member-in;resource=t-app;location=other :: 네트워크 · 위치
- 프리셋: 레거시 인증 차단 :: 기타·EAS 클라이언트를 차단 :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-all;client=c-eas,c-legacy;grant-mode=g-block :: principal=member-in;client=legacy :: 위험 · 프로토콜
- 프리셋: 위험 로그인 → MFA :: 로그인 위험 중간·높음이면 MFA :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-all;signin-risk=sr-high,sr-medium;grant=gc-mfa :: principal=member-in;signin-risk=high;mfa=none :: 위험 · 프로토콜
- 프리셋: 위험 사용자 → 암호 변경 :: 사용자 위험 높음이면 안전한 암호 변경 :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-all;user-risk=ur-high;grant=gc-pwdchange :: principal=member-in;user-risk=high :: 위험 · 프로토콜
- 프리셋: 모바일 앱 보호 (OR) :: 승인된 앱 또는 앱 보호 정책 — 하나만 충족 :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-selected;platform=p-ios,p-android;client=c-modern;grant=gc-approved-app,gc-app-protection;grant-op=go-or :: principal=member-in;resource=t-app;platform=ios;client=ma-approved :: 기기 · 앱
- 프리셋: 보안 정보 등록 보호 :: 신뢰 위치 밖에서는 MFA 등록 전 추가 확인 :: identity=u-all;identity-exclude=x-breakglass;resource=r-ua-secinfo;loc=l-any,l-ex-trusted;grant=gc-mfa :: principal=member-in;resource=t-ua-secinfo;location=other;mfa=none :: 대상 · 작업
- 프리셋: 인증 컨텍스트 + 인증 강도 :: 민감 리소스(인증 컨텍스트)만 피싱 방지 요구 :: identity=u-all;identity-exclude=x-breakglass;resource=r-authctx;grant=gc-strength;sub.gc-strength=phish;sub.r-authctx=c1 :: principal=member-in;resource=t-authctx;mfa=mfa;reg=phish :: 인증
- 프리셋: 에이전트 ID 차단 :: Agent ID 대상 정책 — 허용 컨트롤은 차단만 가능 :: identity=u-agents;resource=r-agent-res;grant-mode=g-block :: principal=agent;resource=t-agent-res :: 대상 · 작업
- 프리셋: 워크로드 ID 위치 제한 :: 서비스 주체는 신뢰 위치 밖에서 차단 :: identity=u-workload;resource=r-apps-all;loc=l-any,l-ex-trusted;grant-mode=g-block :: principal=workload;location=other :: 네트워크 · 위치
- 프리셋: 세션 컨트롤 묶음 :: 허용 후 앱 적용 제한 · 로그인 빈도 · 영구 세션 :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-all;grant=gc-compliant,gc-mfa;grant-op=go-or;session=s-app-restrictions,s-frequency,s-persistent;sub.s-frequency=1d;sub.s-persistent=never;sub.s-app-restrictions=limited :: principal=member-in;resource=t-app-spo;device=byod;client=browser;sessage=2d :: 세션 · 검증
- 프리셋: 보고 전용으로 먼저 검증 :: 강제하지 않고 영향만 기록 :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-all;grant=gc-compliant;state=st-report :: principal=member-in;device=personal :: 세션 · 검증
- 프리셋: SharePoint 비관리 디바이스 제한 :: 앱 적용 제한 — Entra가 디바이스 정보를 SharePoint에 넘기고, 앱 정책(제한된 웹 전용)이 판정 :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-selected;session=s-app-restrictions;sub.s-app-restrictions=limited :: principal=member-in;resource=t-app-spo;device=personal;client=browser :: 세션 · 검증
- 프리셋: 앱 제어 — 다운로드 차단 :: 세션을 Defender for Cloud Apps 프록시로 보내 다운로드를 차단 :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-selected;session=s-mdca;sub.s-mdca=block :: principal=member-in;resource=t-app-spo;device=personal;client=browser;activity=download :: 세션 · 검증
- 프리셋: 토큰 보호 + CAE :: 토큰을 기기에 바인딩하고, 이벤트가 나면 리소스가 토큰을 거부 :: identity=u-all;identity-exclude=x-breakglass;resource=r-apps-selected;session=s-token-protection,s-cae;sub.s-cae=strict :: principal=member-in;resource=t-app-spo;platform=windows;client=ma-other;device=managed;replay=other;caeevt=ipout :: 세션 · 검증
