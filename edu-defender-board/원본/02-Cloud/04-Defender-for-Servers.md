## L2 · Defender for Servers — 플랜과 서버 보안 가시성

- 설정(Control Plane): 구독 또는 커넥터의 Servers 플랜 선택 | Defender for Endpoint 통합 · 스캔 구성
- 강제(Enforcement): 지원 기기의 엔드포인트 보호 및 플랜별 스캔 | 에이전트와 에이전트 없는 경로를 구분
- 증적(Evidence): 서버 인벤토리 · 보안 경고 · 취약성 권장 사항
- 메뉴(Admin Center): Azure portal > Defender for Cloud > Environment settings > Defender plans > Servers
- 라이선스(License): Defender for Servers P1 또는 P2 과금 | 플랜별 대상·기능·비용 [확인 필요: 실제 SKU별 사용 권한과 대상 사용자 조건을 Microsoft Learn 서비스 설명·고객 계약 및 할당된 라이선스에서 대조]

### L3 · 0 · 기능 상태 전이 — 보호 범위 확인 → 플랜 구성 → 서버 조사

#### L4 · ⓪ 비활성 — 서버 플랜을 켜지 않은 구독

1. [시작] 관리자가 서버 보호 범위를 확인한다
   - 주체: 관리자
   - 데이터: Azure VM · 서버 운영체제
   - 해설: 어떤 구독과 서버를 보호할지 먼저 정합니다.
2. [처리] 환경 설정에서 Servers 플랜을 확인한다
   - 주체: 관리자
   - 위치: Defender for Cloud › Environment settings
   - 데이터: 구독의 플랜 상태
   - 해설: 이 예제는 서버 플랜이 꺼져 있습니다.
3. [처리] 기존 기기 보호와 수집 상태를 점검한다
   - 주체: 관리자
   - 데이터: 기존 Defender for Endpoint 온보딩 여부
   - 해설: 플랜 미사용이 서버의 모든 보안 기능 부재를 의미하지는 않습니다.
4. [끝] 보호해야 할 서버와 공백을 기록한다
   - 주체: 관리자
   - 데이터: 대상 서버 목록
   - 해설: 서버별 온보딩과 플랜 지원을 대조합니다.

#### L4 · ① 구성 — 구독의 서버 플랜을 선택한다

1. [시작] 관리자가 구독과 대상 서버를 확인한다
   - 주체: 관리자
   - 위치: Azure portal › 구독
   - 데이터: 구독 · 서버 수 · 관리자 권한 [확인 필요: 실제 SKU별 사용 권한과 대상 사용자 조건을 Microsoft Learn 서비스 설명·고객 계약 및 할당된 라이선스에서 대조]
   - 해설: 서버 수와 과금 범위를 검토합니다.
2. [처리] Defender for Cloud의 환경 설정을 연다
   - 주체: 관리자
   - 위치: Defender for Cloud › Environment settings › 구독
   - 데이터: 구독의 Defender plans
   - 해설: 대상 구독의 플랜을 선택합니다.
3. [처리] Servers 플랜을 켠다
   - 주체: 관리자
   - 위치: Defender plans › Servers
   - 데이터: P1 또는 P2 · 플랜 상태
   - 해설: 요구하는 기능과 비용에 따라 플랜을 선택합니다.
4. [처리] Defender for Endpoint 통합을 검토한다
   - 주체: 관리자
   - 위치: Servers 플랜 설정 › Defender for Endpoint 통합 [확인 필요: 현재 포털 메뉴명과 기능별 경로를 대상 테넌트에서 확인하고 최신 Microsoft Learn 절차와 대조]
   - 데이터: 통합 상태 · 지원 서버
   - 해설: 센서 기반 보호의 온보딩 조건을 확인합니다.
5. [처리] P2의 에이전트 없는 스캔을 검토한다
   - 주체: 관리자
   - 위치: Servers 플랜 설정 › Agentless scanning
   - 데이터: 스캔 구성 · 서버 제외
   - 해설: 지원 범위와 다른 유료 플랜의 제공 여부를 함께 확인합니다.
6. [끝] 저장하고 서버별 상태를 확인한다
   - 주체: 관리자
   - 위치: Defender for Cloud › Inventory
   - 데이터: 서버 목록 · 플랜 상태
   - 해설: 플랜 저장 후 온보딩 및 스캔 결과를 확인합니다.

#### L4 · ▶ ② 활성 — 서버의 보호 및 취약성 결과를 조사한다

1. [시작] Defender for Cloud가 구독의 서버를 식별한다
   - 주체: Defender for Cloud
   - 데이터: 서버 리소스 · 플랜
   - 해설: 대상 서버와 선택한 플랜을 확인합니다.
2. [처리] 운영자가 서버의 보호 상태를 연다
   - 주체: 보안 운영자
   - 위치: Defender for Cloud › Inventory › 서버
   - 데이터: 서버 ID · 온보딩 상태
   - 해설: 센서와 스캔은 서로 다른 데이터 경로입니다.
3. [판단] 조사할 데이터의 구성 요소가 정상인가?
   - 주체: 보안 운영자
   - 데이터: MDE 온보딩 · 스캔 설정 · 지원 범위
   - 해설: 센서 또는 스캔에 필요한 구성 상태를 각각 확인합니다.
   - 정상 → 4
   - 누락 → 6
4. [처리] 경고와 취약성 권장 사항을 검토한다
   - 주체: 보안 운영자
   - 위치: Defender for Cloud › Security alerts · Recommendations
   - 데이터: 서버 경고 · 취약성 결과
   - 해설: 보안 경고와 자세 관리 권장 사항은 서로 다른 결과입니다.
5. [끝] 결과와 대상 서버를 기록한다
   - 주체: 보안 운영자
   - 데이터: 서버 ID · 경고 또는 권장 사항
   - 해설: 결과를 제품과 서버에 연결해 추적합니다.
6. [끝] 온보딩 또는 스캔 미적용 사유를 조사한다
   - 주체: 관리자
   - 데이터: 플랜 · 서버 지원 · 제외 · 권한
   - 해설: 데이터가 없을 때 지원 범위 및 배포 상태를 확인합니다.
- 시나리오: 정상 :: 서버 경고와 취약성 결과 확인
- 시나리오: 누락 :: 서버 온보딩과 스캔 공백 조사

> 주의: P1/P2의 세부 기능, 서버별 과금 및 운영체제 지원은 [확인 필요: 실제 SKU별 사용 권한과 대상 사용자 조건을 Microsoft Learn 서비스 설명·고객 계약 및 할당된 라이선스에서 대조].
> 출처: https://learn.microsoft.com/en-us/azure/defender-for-cloud/plan-defender-for-servers-select-plan

### L3 · A · 스캔 경로 — 센서와 에이전트 없는 검사

#### L4 · 서버 신호 비교 — 서로 다른 수집 경로

1. [시작] 관리자가 서버 보안 데이터 출처를 확인한다
   - 주체: 관리자
   - 데이터: MDE 통합 · 에이전트 없는 스캔
   - 해설: 두 경로는 서로 대체되는 동일한 결과가 아닙니다.
2. [처리] 대상 서버의 플랜과 구성 요소를 연다
   - 주체: 관리자
   - 위치: Defender for Cloud › Environment settings › Servers
   - 데이터: P1/P2 · 스캔 설정
   - 해설: 에이전트 없는 스캔 지원 조건을 확인합니다.
3. [판단] 서버가 스캔 범위에 포함되는가?
   - 주체: Defender for Cloud
   - 데이터: 플랜 · 리소스 유형 · 제외 설정
   - 해설: 제외 또는 미지원 서버는 같은 스캔 결과를 기대할 수 없습니다.
   - 포함 → 4
   - 제외 또는 미지원 → 5
4. [끝] 수집된 취약성 결과를 검토한다
   - 주체: 보안 운영자
   - 데이터: 취약성 권장 사항 · 서버
   - 해설: 결과는 스캔과 평가가 완료된 범위에 한정됩니다.
5. [끝] 지원 범위와 대체 신호를 조사한다
   - 주체: 보안 운영자
   - 데이터: 제외 조건 · 센서 상태
   - 해설: 스캔 공백을 서버가 안전하다는 뜻으로 해석하지 않습니다.
- 시나리오: 포함 :: 스캔된 서버의 취약성 확인
- 시나리오: 제외 또는 미지원 :: 스캔 공백과 센서 상태 확인

> 출처: https://learn.microsoft.com/en-us/azure/defender-for-cloud/plan-defender-for-servers-select-plan
