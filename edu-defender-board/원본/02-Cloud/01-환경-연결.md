## L2 · 환경 연결 — AWS 계정과 Defender for Cloud 연결

- 설정(Control Plane): Azure 구독의 환경 설정에서 AWS 커넥터 생성 | 계정·리전·플랜·AWS 접근 권한 선택
- 강제(Enforcement): AWS 연동 신뢰와 단기 자격 증명으로 리소스 수집·평가 | 선택한 플랜별 추가 구성은 별도
- 증적(Evidence): 환경 설정의 커넥터 상태 · AWS 리소스 인벤토리 · 보안 권장 사항
- 메뉴(Admin Center): Azure portal > Defender for Cloud > Environment settings > Add environment > Amazon Web Services
- 라이선스(License): Defender for Cloud가 켜진 Azure 구독 필요 | Foundational CSPM은 무료, 추가 Defender 플랜은 과금 가능

### L3 · 0 · 기능 상태 전이 — 연결 전 → 커넥터 생성 → AWS 자산 확인

#### L4 · ⓪ 비활성 — AWS 계정을 연결하기 전

1. [시작] 관리자가 AWS 계정의 보안 상태를 확인하려 한다
   - 주체: 관리자
   - 데이터: AWS 계정 ID · Azure 구독
   - 해설: 계정을 연결하기 전에는 이 커넥터 경로가 없습니다.
2. [처리] Azure 환경 설정의 커넥터 목록을 확인한다
   - 주체: 관리자
   - 위치: Azure portal › Defender for Cloud › Environment settings
   - 데이터: 기존 연결된 AWS 계정
   - 해설: 동일 계정이 이미 연결됐는지 먼저 살펴봅니다.
3. [처리] 대상 계정의 리소스가 평가 범위에 없음을 확인한다
   - 주체: 관리자
   - 데이터: 해당 계정의 연결 여부 · 선택 구독 필터
   - 해설: 선택한 구독 필터 때문에 화면에서 보이지 않을 가능성도 확인합니다.
4. [끝] 자산·권장 사항 수집을 위한 연결이 필요하다
   - 주체: 관리자
   - 데이터: AWS 계정 · 연결할 리전
   - 해설: 단일 계정과 조직 관리 계정은 범위가 다릅니다.

#### L4 · ① 구성 — 단일 AWS 계정 커넥터를 만든다

1. [시작] Azure 구독과 AWS 계정 권한을 준비한다
   - 주체: 관리자
   - 위치: Azure portal › 구독 · AWS 콘솔
   - 데이터: Defender for Cloud가 켜진 구독 · Azure Contributor 권한 · AWS 계정 접근
   - 해설: 선택한 플랜은 추가 권한과 구성 요소를 요구할 수 있습니다.
2. [처리] AWS 환경 추가를 연다
   - 주체: 관리자
   - 위치: Azure portal › Defender for Cloud › Environment settings › Add environment › Amazon Web Services
   - 데이터: 커넥터 이름
   - 해설: Azure 구독 안에 보안 커넥터를 만듭니다.
3. [처리] 단일 계정과 AWS 리전을 지정한다
   - 주체: 관리자
   - 위치: Add AWS account › Onboard · AWS regions
   - 데이터: Single account · 계정 ID · 대상 리전
   - 해설: 선택하지 않은 범위의 자산까지 연결된 것으로 간주하지 않습니다.
4. [처리] 커넥터를 둘 구독과 리소스 그룹을 고른다
   - 주체: 관리자
   - 위치: Add AWS account › Subscription · Resource group · Location
   - 데이터: Azure 구독 · 리소스 그룹 · 위치
   - 해설: Azure 쪽 커넥터 배치 위치를 정합니다.
5. [처리] 필요한 플랜을 선택한다
   - 주체: 관리자
   - 위치: Add AWS account › Select plans
   - 데이터: Foundational CSPM · 선택적 유료 플랜
   - 해설: 플랜별 구성 요소, 권한과 추가 비용을 확인합니다.
6. [처리] 접근 권한과 배포 방법을 선택한다
   - 주체: 관리자
   - 위치: Add AWS account › Configure access
   - 데이터: Default access 또는 Least privilege access · CloudFormation 또는 Terraform
   - 해설: 최소 권한 선택 시 나중에 기능 추가에 필요한 권한 알림이 생길 수 있습니다.
7. [끝] AWS 측 배포와 Azure 커넥터 생성을 완료한다
   - 주체: 관리자
   - 위치: AWS 콘솔의 선택한 배포 방법 · Azure portal › Environment settings
   - 데이터: 배포 결과 · 커넥터 설정
   - 해설: AWS 측 배포 결과와 Azure의 연결 상태를 둘 다 확인합니다.

#### L4 · ② 활성 — 연결 상태와 계정 내 자산을 확인한다

1. [시작] Defender for Cloud가 구성된 AWS 계정 접근을 시도한다
   - 주체: Defender for Cloud
   - 데이터: 커넥터 · 계정 ID · 연동 신뢰
   - 해설: AWS 인증은 장기 비밀을 저장하지 않는 연동 신뢰와 단기 자격 증명을 사용합니다.
2. [판단] AWS 측 배포와 접근이 정상인가?
   - 주체: Defender for Cloud
   - 데이터: 커넥터 상태 · AWS 배포 결과
   - 해설: 배포나 권한을 확인할 수 없는 경우 자산 부재를 정상으로 간주하지 않습니다.
   - 정상 → 3
   - 오류 → 6
3. [처리] 선택한 계정과 리전의 리소스를 수집한다
   - 주체: Defender for Cloud
   - 데이터: 리소스 메타데이터 · 커넥터 범위
   - 해설: 수집 범위는 연결한 계정과 선택한 리전에 종속됩니다.
4. [처리] 자산 인벤토리와 보안 권장 사항을 조회한다
   - 주체: 관리자
   - 위치: Defender for Cloud › Inventory · Recommendations [확인 필요: 현재 포털 메뉴명과 기능별 경로를 대상 테넌트에서 확인하고 최신 Microsoft Learn 절차와 대조]
   - 데이터: 자산 · 보안 평가 결과
   - 해설: 자산 검색과 권장 사항 평가는 서로 다른 결과입니다.
5. [끝] 커넥터 범위와 발견된 자산을 대조한다
   - 주체: 관리자
   - 데이터: 계정 ID · 리전 · 인벤토리 결과
   - 해설: 모든 AWS 계정과 리전이 자동으로 포함됐다고 가정하지 않습니다.
6. [끝] AWS 배포 또는 접근 오류를 조사한다
   - 주체: 관리자
   - 데이터: AWS 배포 상태 · 권한 · 커넥터 상태
   - 해설: 권한 부족, 배포 오류 또는 미완료 여부를 구별합니다.
- 시나리오: 정상 :: 연결된 계정과 리전의 자산 확인
- 시나리오: 오류 :: AWS 배포 또는 접근 오류 조사

> 교육 포인트: 이 예제는 단일 AWS 계정이다. 관리 계정 연결에서는 구성원 계정 자동 프로비저닝과 제외 계정을 별도로 검토한다.
> 주의: 선택 플랜별 비용·추가 권한 및 실제 표시 메뉴는 [확인 필요: 현재 포털 메뉴명과 기능별 경로를 대상 테넌트에서 확인하고 최신 Microsoft Learn 절차와 대조].

### L3 · A · 계정 범위 — 단일 계정과 조직 연결

#### L4 · 계정 유형 선택 — 수집 범위와 제외를 비교한다

1. [시작] 관리자가 보호할 AWS 계정 범위를 정한다
   - 주체: 관리자
   - 데이터: 단일 AWS 계정 또는 조직 관리 계정
   - 해설: 계정 유형은 생성되는 커넥터 범위에 영향을 줍니다.
2. [처리] 환경 추가 화면에서 계정 유형을 선택한다
   - 주체: 관리자
   - 위치: Defender for Cloud › Environment settings › Add environment › Amazon Web Services
   - 데이터: Single account · Management account
   - 해설: 관리 계정 온보딩에는 AWS 관리 계정을 사용합니다.
3. [판단] 조직 관리 계정을 선택했는가?
   - 주체: 관리자
   - 데이터: 선택한 계정 유형
   - 해설: 위임 관리자 계정은 이 관리 계정 온보딩에 지원되지 않습니다.
   - 단일 계정 → 4
   - 관리 계정 → 5
4. [끝] 지정한 단일 계정의 커넥터를 확인한다
   - 주체: 관리자
   - 데이터: 단일 계정 ID · 선택 리전
   - 해설: 다른 계정은 이 단일 계정 커넥터에 포함되지 않습니다.
5. [처리] 제외할 구성원 계정을 지정한다
   - 주체: 관리자
   - 위치: Add AWS account › 제외할 AWS 계정 ID
   - 데이터: 제외 계정 ID 목록
   - 해설: 관리 계정 연결 시 필요한 제외 대상을 명시합니다.
6. [끝] 구성원 계정의 자동 프로비저닝 범위를 확인한다
   - 주체: 관리자
   - 데이터: 검색된 구성원 · 새 구성원 · 제외 목록
   - 해설: 자동 프로비저닝으로 검색되거나 새로 생긴 구성원 커넥터를 확인합니다.
- 시나리오: 단일 계정 :: 선택한 단일 계정만 연결 범위 확인
- 시나리오: 관리 계정 :: 구성원 자동 연결과 제외 계정 확인

> 출처: https://learn.microsoft.com/en-us/azure/defender-for-cloud/quickstart-onboard-aws
