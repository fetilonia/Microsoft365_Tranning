## L2 · DLP (M365) — SharePoint · OneDrive 외부 공유 통제

- 설정(Control Plane): DLP 정책·위치·콘텐츠 조건·외부 공유 조건·동작
- 강제(Enforcement): 적용 위치의 DLP 정책이 일치 콘텐츠의 외부 사용자 접근 제한
- 증적(Evidence): 정책 시뮬레이션 결과 | 구성된 DLP 경고·Activity explorer [확인 필요: 이벤트별 기록]
- 메뉴(Admin Center): Data loss prevention > Policies > Create policy
- 라이선스(License): DLP 위치·조건·동작별 구독 및 대상 사용자 요건 [확인 필요: 고객 SKU]

### L3 · 0 · 기능 상태 전이 — 정책 없음 → 시뮬레이션 구성 → 외부 공유 평가

#### L4 · ⓪ 비활성 — 예제 정책이 아직 없음

1. [시작] 관리자가 외부 공유 보호 목표 정의
   - 주체: 관리자
   - 데이터: 교육용 민감 콘텐츠와 외부 수신자
   - 해설: 이 예제는 SharePoint와 OneDrive를 대상으로 합니다.
2. [처리] 해당 조건을 가진 새 DLP 정책은 아직 구성하지 않음
   - 주체: 관리자
   - 데이터: 예제의 정책 미생성 상태
   - 해설: 기존 보안 설정이나 다른 DLP 정책이 없는 것은 아닙니다.
3. [처리] 저장소 공유 권한과 기존 보호 확인
   - 주체: 관리자
   - 위치: SharePoint · OneDrive 공유 설정
   - 데이터: 공유 범위와 기존 정책
   - 해설: 저장소 공유 설정과 DLP 판정은 별도입니다.
4. [끝] 민감 콘텐츠의 추가 통제 필요성 평가
   - 주체: 관리자
   - 데이터: 대상 사이트·유형·예외
   - 해설: 차단 대상을 명확히 한 뒤 테스트 정책을 설계합니다.

#### L4 · ① 구성 — 외부 공유 및 민감 콘텐츠 조건 만들기

1. [시작] 관리자가 역할과 라이선스 확인
   - 주체: 관리자
   - 위치: Microsoft Purview portal
   - 데이터: DLP 정책 관리 권한과 대상 사용자 구독
   - 해설: 고객 테넌트의 권한과 기능별 라이선스를 확인합니다.
2. [처리] 사용자 지정 정책 만들기
   - 주체: 관리자
   - 위치: Data loss prevention › Policies › Create policy › Enterprise applications & devices › Custom
   - 데이터: 정책 이름과 설명
   - 해설: 정책 목적과 적용 범위를 기재합니다.
3. [처리] SharePoint와 OneDrive 위치 선택
   - 주체: 관리자
   - 위치: 정책 위치 선택
   - 데이터: SharePoint sites · OneDrive accounts 및 포함·제외 범위
   - 해설: 예제에서는 다른 위치는 선택하지 않습니다.
4. [처리] 외부 공유와 콘텐츠 조건 추가
   - 주체: 관리자
   - 위치: Create or customize advanced DLP rules › Create rule
   - 데이터: Shared outside my organization AND Content contains 선택한 SIT
   - 해설: 외부 공유와 민감 콘텐츠 조건을 함께 충족하도록 합니다.
5. [처리] 외부 사용자 접근 제한 동작 설정
   - 주체: 관리자
   - 위치: Actions › Restrict access or encrypt the content in Microsoft 365 locations › Block only people outside your organization
   - 데이터: 차단 동작 및 사용자 알림·재정의 설정
   - 해설: 이 예제는 재정의를 허용하지 않습니다.
6. [처리] 경고와 시뮬레이션 선택
   - 주체: 관리자
   - 위치: Incident reports 및 Policy mode
   - 데이터: 관리자 경고·Run the policy in simulation mode
   - 해설: 먼저 테스트하여 일치 범위를 검토합니다.
7. [끝] 정책 저장 후 시뮬레이션 검토
   - 주체: 관리자
   - 위치: DLP › Policies
   - 데이터: 정책 상태와 테스트 결과
   - 해설: 예상한 결과를 확인한 다음 운영 강제를 결정합니다.

#### L4 · ② 활성 — 외부 공유에서 규칙을 평가

1. [시작] 사용자가 교육용 파일을 외부에 공유
   - 주체: 사용자
   - 위치: SharePoint 또는 OneDrive
   - 데이터: 정책 대상 위치·파일·외부 수신자
   - 해설: 예제는 정책이 활성이고 대상 범위에 포함됩니다.
2. [처리] DLP가 외부 공유 조건 확인
   - 주체: DLP 서비스
   - 위치: SharePoint · OneDrive DLP 평가
   - 데이터: 공유 대상의 조직 외부 여부
   - 해설: 내부 공유와 외부 공유는 이 규칙에서 다릅니다.
3. [판단] 파일이 선택한 SIT 조건과 일치하는가?
   - 주체: DLP 서비스
   - 데이터: 파일 분류 결과와 규칙의 SIT 조건
   - 해설: 외부 공유가 맞더라도 콘텐츠 조건도 만족해야 합니다.
   - 일치 → 4
   - 불일치 → 6
4. [처리] 외부 사용자 접근 제한 적용
   - 주체: DLP 서비스
   - 위치: 대상 SharePoint 또는 OneDrive 항목
   - 데이터: 외부 사용자 접근 제한
   - 해설: 활성 정책의 설정된 차단 동작이 적용됩니다.
5. [끝] 구성된 경고와 사용자 알림 조사
   - 주체: 관리자
   - 위치: DLP 경고 및 Activity explorer
   - 데이터: 규칙 일치와 정책 동작
   - 해설: 알림과 증적의 가용성은 정책 설정 및 지원 범위에 따릅니다.
6. [끝] 이 규칙은 콘텐츠 조건에 일치하지 않음
   - 주체: 관리자
   - 데이터: 콘텐츠 불일치 판정
   - 해설: 이 규칙의 차단이 없다는 뜻이며 다른 정책의 결과는 별도입니다.
- 시나리오: 일치 :: 민감 파일의 외부 사용자 접근 제한
- 시나리오: 불일치 :: SIT 불일치로 이 규칙의 제한 미적용

> 교육 포인트: 외부 공유와 민감 콘텐츠 조건은 AND이며 다른 정책도 별도로 평가될 수 있습니다.

### L3 · A · 시뮬레이션과 강제

#### L4 · 같은 일치 항목을 정책 모드별로 비교 — 시뮬레이션과 실제 제한

1. [시작] 외부 공유 및 SIT 조건에 일치하는 파일 준비
   - 주체: 관리자
   - 위치: 정책 대상 SharePoint 사이트
   - 데이터: 교육용 SIT와 외부 공유 대상
   - 해설: 동일한 조건에서 정책 모드만 바꿔 비교합니다.
2. [처리] 정책 모드 확인
   - 주체: 관리자
   - 위치: Data loss prevention › Policies › 정책
   - 데이터: 시뮬레이션 또는 활성 모드
   - 해설: 시뮬레이션은 실제 강제 전에 정책 영향을 검토하는 단계입니다.
3. [처리] 외부 공유 조건과 SIT 일치 평가
   - 주체: DLP 서비스
   - 데이터: 외부 공유와 민감 콘텐츠의 일치
   - 해설: 이 예제에서는 두 조건 모두 일치합니다.
4. [판단] 정책이 시뮬레이션 모드인가?
   - 주체: DLP 서비스
   - 데이터: 정책 모드
   - 해설: 표시되는 정책 팁과 실제 차단은 구별해야 합니다.
   - 예 → 5
   - 아니오 → 6
5. [끝] 강제하지 않고 시뮬레이션 결과 검토
   - 주체: 관리자
   - 위치: 정책 시뮬레이션 결과
   - 데이터: 일치 항목과 설정한 테스트 알림
   - 해설: 시뮬레이션의 일치는 실제 차단 증거가 아닙니다.
6. [끝] 활성 정책의 외부 접근 제한 확인
   - 주체: 관리자
   - 위치: 공유 항목 및 구성된 DLP 경고
   - 데이터: 실제 적용된 접근 제한
   - 해설: 활성 정책의 동작과 사용자가 받은 알림을 확인합니다.
- 시나리오: 예 :: 시뮬레이션으로 일치만 검토
- 시나리오: 아니오 :: 활성 정책으로 외부 접근 제한
