## L2 · Copilot 위치 DLP — 프롬프트 · 웹 검색 · 레이블 · 외부 메일

- 설정(Control Plane): Microsoft Copilot · Copilot Chat · Copilot Cowork 위치 | SIT·레이블·외부 메일 조건별 규칙
- 강제(Enforcement): 선택한 동작에 따라 프롬프트 처리·외부 웹 검색 또는 근거 콘텐츠 처리 제한
- 증적(Evidence): 사용자 정책 메시지 | DLP 활동·경고 [확인 필요: 동작별 이벤트와 표시 범위]
- 메뉴(Admin Center): Data loss prevention > Policies > Create policy > Microsoft Copilot, Copilot Chat, and Copilot Cowork
- 라이선스(License): Copilot과 DLP 동작별 구독 및 대상 사용자 요건 [확인 필요: 고객 SKU·미리 보기 적용]

### L3 · 0 · 기능 상태 전이 — 정책 전 → 민감 프롬프트 규칙 → 평가

#### L4 · ⓪ 비활성 — 예제의 민감 프롬프트 규칙 미구성

1. [시작] 관리자가 Copilot 데이터 보호 목표 확인
   - 주체: 관리자
   - 데이터: 교육용 SIT와 대상 사용자
   - 해설: 프롬프트, 웹 검색, 근거 콘텐츠는 서로 다른 통제 대상입니다.
2. [처리] 예제의 프롬프트 제한 규칙은 아직 만들지 않음
   - 주체: 관리자
   - 데이터: 예제 규칙 미구성
   - 해설: 다른 DLP 정책이나 기존 접근 제어의 존재 여부와는 별개입니다.
3. [처리] Copilot 사용자의 기존 접근 권한 확인
   - 주체: 관리자
   - 데이터: 사용자와 Microsoft 365 데이터의 접근 권한
   - 해설: DLP 정책을 만들기 전에도 기존 권한은 검토해야 합니다.
4. [끝] 민감한 텍스트를 넣지 않을 교육 예제 준비
   - 주체: 관리자
   - 데이터: 가상 양성·음성 프롬프트
   - 해설: 실제 민감 데이터를 사용하지 않고 정책을 시험합니다.

#### L4 · ① 구성 — SIT 프롬프트 제한 규칙 만들기

1. [시작] 지원 상태와 역할 확인
   - 주체: 관리자
   - 위치: Purview DLP 정책 및 Microsoft Copilot 위치
   - 데이터: 정책 편집 역할·사용자 구독·테넌트 배포 상태
   - 해설: 프롬프트 제한은 공식 문서상 미리 보기이며 테넌트 적용 여부를 확인합니다.
2. [처리] 사용자 지정 DLP 정책 만들기
   - 주체: 관리자
   - 위치: Data Loss Prevention › Policies › Create policy › Custom policy
   - 데이터: 정책 이름과 대상
   - 해설: 교육용 사용자 범위에 정책을 제한합니다.
3. [처리] Copilot 위치 선택
   - 주체: 관리자
   - 위치: Locations › Microsoft Copilot, Copilot Chat, and Copilot Cowork
   - 데이터: 해당 위치와 포함 사용자·그룹
   - 해설: 지원되는 Copilot 경험과 배포 상태를 확인합니다.
4. [처리] SIT 조건 추가
   - 주체: 관리자
   - 위치: 정책 규칙 › Content contains › Sensitive information types
   - 데이터: 기본 제공 또는 사용자 지정 SIT
   - 해설: 프롬프트 텍스트에서 검사할 유형을 선택합니다.
5. [처리] 프롬프트 처리 제한 동작 설정
   - 주체: 관리자
   - 위치: 규칙 동작 › Restrict Copilot from processing content › Processing prompts
   - 데이터: 프롬프트 처리 제한
   - 해설: 외부 웹 검색만 제한하는 동작과 구분합니다.
6. [처리] 레이블 조건이 필요하면 별도 규칙 작성
   - 주체: 관리자
   - 위치: DLP 정책 규칙
   - 데이터: SIT 규칙과 레이블 규칙
   - 해설: SIT와 민감도 레이블 조건은 같은 규칙에 함께 넣을 수 없습니다.
7. [끝] 정책 배포 및 테스트
   - 주체: 관리자
   - 위치: DLP 정책 상태 및 지원 Copilot 경험
   - 데이터: 정책 적용 사용자와 테스트 결과
   - 해설: 미리 보기 범위와 메시지 표시를 검증합니다.

#### L4 · ② 활성 — 민감 프롬프트를 평가

1. [시작] 대상 사용자가 프롬프트 제출
   - 주체: 사용자
   - 위치: 지원되는 Copilot 경험
   - 데이터: 교육용 프롬프트 텍스트
   - 해설: 예제 정책은 활성화되어 있습니다.
2. [처리] DLP가 프롬프트 텍스트의 SIT 평가
   - 주체: DLP 서비스
   - 데이터: 선택한 SIT 및 입력 텍스트
   - 해설: 직접 업로드한 파일의 내용은 이 텍스트 검사에 포함되지 않습니다.
3. [판단] 프롬프트가 규칙의 SIT에 일치하는가?
   - 주체: DLP 서비스
   - 데이터: SIT 일치 결과
   - 해설: 규칙 조건이 충족될 때 설정한 동작이 적용됩니다.
   - 일치 → 4
   - 불일치 → 6
4. [처리] Copilot의 민감 프롬프트 처리 제한
   - 주체: Copilot
   - 데이터: 처리 제한된 프롬프트
   - 해설: 응답을 반환하지 않으며 해당 민감 데이터로 내부·외부 검색을 하지 않습니다.
5. [끝] 사용자 안내와 정책 결과 조사
   - 주체: 관리자
   - 위치: 사용자 경험 및 지원되는 DLP 활동
   - 데이터: 정책 제한 메시지·활동 기록
   - 해설: 앱에 따라 미리 보기 메시지는 원인을 명확히 표시하지 않을 수 있습니다.
6. [끝] 이 SIT 규칙의 프롬프트 제한은 적용되지 않음
   - 주체: Copilot
   - 데이터: SIT 불일치
   - 해설: 다른 규칙이나 권한으로부터 자유롭다는 뜻은 아닙니다.
- 시나리오: 일치 :: 민감 프롬프트가 일치해 응답 제한
- 시나리오: 불일치 :: 해당 SIT 규칙은 프롬프트를 제한하지 않음

> 주의: 프롬프트 차단은 미리 보기입니다. 프롬프트에 직접 첨부한 파일 내용은 이 DLP 텍스트 검사에서 스캔하지 않습니다.

### L3 · A · 동작별 차이 — 대표 시나리오: 민감 프롬프트의 외부 웹 검색 제한

#### L4 · 웹 검색과 전체 처리 제한 비교 — 같은 SIT에 다른 동작 지정

1. [시작] SIT에 일치하는 가상 프롬프트 준비
   - 주체: 관리자
   - 데이터: 동일한 SIT와 두 정책 동작
   - 해설: 두 동작을 개별 테스트 환경에서 비교합니다.
2. [처리] Copilot 위치의 규칙 조건 설정
   - 주체: 관리자
   - 위치: DLP › Policies › 규칙
   - 데이터: Content contains › Sensitive information types
   - 해설: 조건은 같고 동작만 다릅니다.
3. [처리] 프롬프트를 제출하고 일치 판정
   - 주체: 사용자
   - 데이터: 일치하는 프롬프트 텍스트
   - 해설: 해당 규칙이 사용자에게 적용된다고 가정합니다.
4. [판단] 규칙 동작이 웹 검색 제한인가?
   - 주체: DLP 서비스
   - 데이터: Performing Web Searches 또는 Processing prompts
   - 해설: 두 동작은 사용자가 받는 결과가 다릅니다.
   - 웹 검색 제한 → 5
   - 프롬프트 제한 → 6
5. [끝] 외부 웹 검색을 제외하고 허용된 내부 자료로 응답
   - 주체: Copilot
   - 데이터: 외부 검색 제외·허용된 내부 자료
   - 해설: 웹 검색 제한만으로 전체 응답을 차단하는 것은 아닙니다.
6. [끝] 프롬프트 처리와 응답 제한
   - 주체: Copilot
   - 데이터: 처리 제한 결과
   - 해설: Processing prompts는 응답을 반환하지 않습니다.
- 시나리오: 웹 검색 제한 :: 외부 웹 검색 제외 후 내부 자료 사용
- 시나리오: 프롬프트 제한 :: 민감 프롬프트 처리와 응답 제한

> 교육 포인트: 레이블로 지정한 파일·이메일은 처리에서 제외되어도 인용에 표시될 수 있습니다. 외부 발신 메일 제외는 미리 보기이며 Cowork는 아직 지원하지 않습니다.
> 출처: https://learn.microsoft.com/en-us/purview/dlp-microsoft365-copilot-location-learn-about

### L3 · B · 레이블 항목 처리 — 근거에서 제외되는 파일과 이메일

#### L4 · 레이블 일치 항목 비교 — 프롬프트 제한과 콘텐츠 제외를 구분

1. [시작] 관리자가 교육용 파일 두 개 준비
   - 주체: 관리자
   - 데이터: 제한 대상 레이블이 있는 파일과 없는 파일
   - 해설: 두 파일은 사용자가 접근할 권한을 가진다고 가정합니다.
2. [처리] 별도 레이블 조건 규칙 구성
   - 주체: 관리자
   - 위치: DLP › Policies › Copilot 위치 › Content contains › Sensitivity labels
   - 데이터: 처리에서 제외할 레이블과 사용자 대상
   - 해설: SIT 프롬프트 조건과 같은 규칙에 혼합하지 않습니다.
3. [처리] 사용자가 지원 Copilot에서 파일을 근거로 요청
   - 주체: 사용자
   - 위치: 지원되는 Copilot 경험
   - 데이터: 사용자 요청과 후보 파일의 레이블
   - 해설: 요청 텍스트와 근거 파일은 다른 검사 대상입니다.
4. [판단] 파일의 레이블이 제외 규칙에 일치하는가?
   - 주체: DLP 서비스
   - 데이터: 파일의 민감도 레이블·정책 조건
   - 해설: 다른 정책과 권한은 별도입니다.
   - 일치 → 5
   - 불일치 → 6
5. [끝] 항목 내용을 응답 생성에 사용하지 않음
   - 주체: Copilot
   - 데이터: 제외된 파일·인용 표시 가능성
   - 해설: 항목이 인용에 나타날 수 있지만 내용은 접근하거나 사용하지 않습니다.
6. [끝] 이 레이블 규칙은 항목을 제외하지 않음
   - 주체: Copilot
   - 데이터: 레이블 조건 불일치
   - 해설: 다른 정책·접근 권한·제품 지원에 따라 결과가 달라질 수 있습니다.
- 시나리오: 일치 :: 대상 레이블 파일 내용을 근거 처리에서 제외
- 시나리오: 불일치 :: 이 레이블 규칙의 콘텐츠 제외 미적용

> 주의: 레이블 조건의 이메일은 2025-01-01 이후 발송된 항목을 지원하며 일정 초대는 지원하지 않습니다. 열린 Word·Excel·PowerPoint 문서에는 추가 앱 경험 제한이 있습니다.
> 출처: https://learn.microsoft.com/en-us/purview/dlp-microsoft365-copilot-location-learn-about

### L3 · C · 외부 발신 메일 — 미리 보기의 근거 제한

#### L4 · 외부 발신 여부 비교 — 허용 도메인과 발신자를 확인

1. [시작] 내부 및 외부 발신 테스트 메일 준비
   - 주체: 관리자
   - 데이터: 테넌트 허용 도메인과 두 발신자 도메인
   - 해설: 미리 보기 기능의 테넌트 지원 상태를 확인합니다.
2. [처리] 외부 사용자 발신 조건 구성
   - 주체: 관리자
   - 위치: DLP › Policies › Copilot 위치 › Email is received from › External users
   - 데이터: 발신 도메인 조건·콘텐츠 처리 방지 동작
   - 해설: 이 규칙은 메일 본문이 아니라 발신 도메인 메타데이터를 평가합니다.
3. [처리] 사용자가 지원 Copilot에 받은 편지함 요약 요청
   - 주체: 사용자
   - 위치: Microsoft 365 Copilot 또는 Copilot Chat
   - 데이터: 사용자에게 접근 가능한 메일
   - 해설: 외부 메일 차단은 아직 Cowork에서 지원되지 않습니다.
4. [판단] 메일 발신자가 조직 외부인가?
   - 주체: DLP 서비스
   - 데이터: 발신 도메인과 테넌트의 허용 도메인
   - 해설: 외부 발신 여부에 따라 이 규칙의 결과가 달라집니다.
   - 외부 → 5
   - 내부 → 6
5. [끝] 외부 메일을 근거·요약·인용에서 제외
   - 주체: Copilot
   - 데이터: 제외된 외부 메일
   - 해설: 사용자 본인의 메일 접근 권한은 바뀌지 않습니다.
6. [끝] 이 외부 발신 조건으로는 제외하지 않음
   - 주체: Copilot
   - 데이터: 내부 발신 메일
   - 해설: 다른 DLP 규칙과 권한은 별도로 평가됩니다.
- 시나리오: 외부 :: 외부 발신 메일을 Copilot 근거에서 제외
- 시나리오: 내부 :: 내부 발신 메일에는 이 외부 조건 미적용

> 출처: https://learn.microsoft.com/en-us/purview/dlp-microsoft365-copilot-location-learn-about
