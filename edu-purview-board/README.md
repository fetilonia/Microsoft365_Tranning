# Purview 교육 보드 초안

[보드 열기](edu-purview-board.html) · [기능별 원고](원본/) · [기존 분리본](../entra-edu-board/split/03-Purview.md)

기능별 설정 · 강제 · 증적과 L3/L4 시나리오를 보여 줍니다. Information Protection은 솔루션 카드의 기준 구현이며, 분류 기능에 패턴 기반 SIT·EDM·학습 가능한 분류자·문서 지문 시나리오를 둡니다. 이 네 항목은 같은 유형의 SIT 하위 유형이 아니며, 공식 문서에서 확인한 관계로 표시합니다. 다른 솔루션 원고는 이번 범위에서 재작성하지 않았습니다. 테넌트·라이선스별 조건은 확인이 필요합니다.

`원본/`의 기능별 MD를 수정한 뒤 저장소 루트에서 `python build_edu_boards.py`를 실행하면 이 보드를 포함한 네 보드가 다시 생성됩니다. 기능과 시나리오 작성 형식은 [Entra 보드 규격](../entra-edu-board/원본/00-보드-규격.md)을 참고합니다.
