## L2 · 안전 시스템 — 유해 · 보호 자료 · 프롬프트 인젝션

- 설정(Control Plane): Microsoft의 다층 보호 | 관리자가 구성하는 DLP 및 메일 보호
- 강제(Enforcement): 프롬프트 입력 · grounding · 응답 단계의 보호 | 조건별 정책 적용
- 증적(Evidence): Copilot 상호작용 감사의 JailbreakDetected | Defender 메일 탐지 [확인 필요: 경고와 기록 위치]
- 메뉴(Admin Center): Microsoft Purview > 감사 | Microsoft Defender 포털 > 정책 및 규칙 [확인 필요: 메뉴]
- 라이선스(License): Defender for Office 365 Plan 2 메일 인젝션 보호 | Purview·기타 보호의 SKU 및 역할 [확인 필요]

### L3 · 0 · 기능 상태 전이 — 보호 경계 이해 → 관리자 통제 검토 → 증적 조사

#### L4 · ⓪ 기준 — Microsoft 기본 보호와 조직 통제 구분

1. [시작] 관리자가 Copilot 사용 경로를 확인
   - 주체: 관리자
   - 데이터: 프롬프트 · 조직 콘텐츠 · 웹 · 응답
   - 해설: 보호는 입력부터 응답까지 여러 단계에 걸칩니다.
2. [처리] Microsoft가 운영하는 보호를 확인
   - 주체: Microsoft
   - 데이터: 유해 콘텐츠 · 프롬프트 인젝션 완화
   - 해설: 일부 보호는 Microsoft가 운영하며 고객용 켜기 스위치로 가정하지 않습니다.
3. [처리] 관리자가 별도로 설정하는 정책을 검토
   - 주체: 관리자
   - 데이터: Purview DLP · Defender 메일 보호
   - 해설: 일부 정책은 조직이 구성하고 라이선스가 필요할 수 있습니다.
4. [끝] 보호와 탐지의 한계를 이해
   - 주체: 관리자
   - 데이터: 서비스 및 정책의 적용 범위
   - 해설: 다층 보호는 위험을 줄이지만 모든 공격 탐지나 차단을 보장하지 않습니다.

#### L4 · ① 구성 — 적용 가능한 보호와 조사 경로 검토

1. [시작] 관리자가 Copilot 사용자를 확인
   - 주체: 관리자
   - 위치: Microsoft 365 관리 센터 › 사용자
   - 데이터: 사용자 · 적용 경험
   - 해설: 보호할 사용자와 사용 중인 경험을 정합니다.
2. [처리] 프롬프트 보호의 Microsoft 운영 범위를 확인
   - 주체: 관리자
   - 위치: Microsoft Copilot 보안 문서
   - 데이터: 입력 · grounding · 응답 단계
   - 해설: Microsoft 운영 보호와 조직이 설정하는 정책을 구분합니다.
3. [처리] Copilot 대상 DLP 정책을 검토
   - 주체: 관리자
   - 위치: Microsoft Purview › 데이터 손실 방지 [확인 필요: 메뉴]
   - 데이터: 대상 사용자 · 정책 조건 · 작업
   - 해설: 민감한 프롬프트나 콘텐츠에 대한 정책을 별도로 확인합니다.
4. [처리] 메일 인젝션 보호의 적용 가능성을 확인
   - 주체: 관리자
   - 위치: Microsoft Defender 포털 [확인 필요: 메뉴]
   - 데이터: Defender for Office 365 Plan 2 · 메일 보호
   - 해설: 수신 메일의 인젝션 탐지는 별도 보안 제품 기능입니다.
5. [처리] 감사 검색 역할과 범위를 확인
   - 주체: 관리자
   - 위치: Microsoft Purview › 감사
   - 데이터: Copilot 상호작용 · 검색 권한
   - 해설: 감사 기록을 검색할 권한과 대상 기간을 준비합니다.
6. [끝] 테스트와 예외 조사 계획을 기록
   - 주체: 관리자
   - 위치: 조직의 보안 운영 절차
   - 데이터: 안전한 테스트 입력 · 조사 담당자
   - 해설: 실제 민감 정보 없이 검증하고 각 도구의 기록 범위를 확인합니다.

#### L4 · ② 적용 — 프롬프트와 콘텐츠 처리 단계 관찰

1. [시작] 사용자가 Copilot에 질문을 보낸다
   - 주체: 사용자
   - 데이터: 프롬프트
   - 해설: 사용자 입력이 Copilot 처리 흐름에 들어갑니다.
2. [처리] 입력 단계에서 보호가 적용
   - 주체: Microsoft Copilot
   - 데이터: 프롬프트 · 운영 보호 · 적용 DLP
   - 해설: 서비스 보호와 조직의 정책이 각각 적용될 수 있습니다.
3. [처리] 접근 가능한 조직 콘텐츠를 grounding
   - 주체: Copilot
   - 데이터: 문서 · 메시지 · 사용자 권한
   - 해설: 콘텐츠의 권한과 별도 보호 정책을 고려합니다.
4. [처리] 허용된 경우 웹 검색 결과를 사용
   - 주체: Copilot
   - 데이터: 웹 콘텐츠 · 웹 검색 설정
   - 해설: 웹 검색은 조직 데이터 grounding과 별도 경로입니다.
5. [처리] 응답 단계의 보호를 적용
   - 주체: Microsoft Copilot
   - 데이터: 생성된 응답
   - 해설: 응답 제공 전에도 보호 계층이 적용됩니다.
6. [끝] 관련 감사와 보안 신호를 조사
   - 주체: 관리자
   - 위치: Microsoft Purview › 감사 · Microsoft Defender 포털
   - 데이터: Copilot 상호작용 · 별도 메일 탐지
   - 해설: 감사와 보안 제품의 신호는 각 도구에서 별도로 조사합니다.

> 교육 포인트: 직접 프롬프트와 외부 콘텐츠의 간접 인젝션은 입력 경로가 다릅니다. 확인일 2026-11-24.
> 출처: https://learn.microsoft.com/en-us/copilot/plan/copilot-prompt-defense-in-depth

### L3 · A · 프롬프트 처리의 다층 보호 — 입력과 콘텐츠 경로 비교

#### L4 · 위험한 지시의 출처 — 직접 입력과 외부 콘텐츠

1. [시작] 사용자가 Copilot 상호작용을 시작
   - 주체: 사용자
   - 데이터: 질문 · 가능한 참조 콘텐츠
   - 해설: 위험한 지시는 사용자 입력 또는 검색 콘텐츠에 있을 수 있습니다.
2. [판단] 사용자 프롬프트 자체에 탈옥 시도가 있는가?
   - 주체: Microsoft Copilot
   - 데이터: 프롬프트 · 보호 신호
   - 해설: 직접 공격은 사용자가 입력한 프롬프트에 포함됩니다.
   - 직접 시도 → 6
   - 직접 시도 아님 → 3
3. [판단] 검색된 콘텐츠에 간접 지시가 있는가?
   - 주체: Microsoft Copilot
   - 데이터: 참조 문서 · 메시지 · 웹 콘텐츠
   - 해설: 간접 공격은 사용자 프롬프트가 참조하는 콘텐츠에 지시가 포함되는 경우입니다.
   - 의심 콘텐츠 → 7
   - 일반 콘텐츠 → 4
4. [처리] 허용된 콘텐츠를 활용해 응답
   - 주체: Copilot
   - 데이터: 접근 권한 · 검색된 콘텐츠
   - 해설: 일반적인 요청도 접근 권한과 적용 정책을 따릅니다.
5. [끝] 상호작용 조사 경로 확인
   - 주체: 관리자
   - 위치: Microsoft Purview › 감사
   - 데이터: 상호작용 · 접근한 리소스
   - 해설: 감사 기록과 프롬프트 본문은 별도 조사 경로입니다.
6. [끝] 직접 탈옥 시도 — 보호 반응과 감사 신호 조사
   - 주체: 관리자
   - 위치: Microsoft Purview › 감사
   - 데이터: JailbreakDetected · 실제 응답 [확인 필요: 기록 조건]
   - 해설: 문서에서 설명하는 신호를 조사하되 탐지나 차단을 보장하지 않습니다.
7. [끝] 간접 의심 콘텐츠 — 출처와 적용 보호 조사
   - 주체: 관리자
   - 데이터: 콘텐츠 출처 · 적용 가능한 보호 [확인 필요]
   - 해설: 내용의 출처와 사용자에게 표시된 결과를 조사합니다.
- 시나리오: 직접 시도 :: 직접 탈옥 시도와 감사 신호 조사
- 시나리오: 직접 시도 아님 ▸ 의심 콘텐츠 :: 외부 콘텐츠의 간접 지시를 조사
- 시나리오: 직접 시도 아님 ▸ 일반 콘텐츠 :: 일반 요청의 권한과 응답 확인

> 주의: Defender for Office 365 Plan 2의 수신 메일 인젝션 탐지는 별도 경로입니다. 탐지 시 사용자 경험과 Defender 증적은 [확인 필요]. 오류나 유해 응답의 사용자 피드백 설정은 별도로 확인합니다.
> 출처: https://learn.microsoft.com/en-us/copilot/plan/copilot-prompt-defense-in-depth
