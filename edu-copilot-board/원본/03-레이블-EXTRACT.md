## L2 · 레이블 · EXTRACT — 암호화 문서 처리

- 설정(Control Plane): 민감도 레이블의 암호화 사용 권한 | 별도 Copilot DLP 정책
- 강제(Enforcement): 사용자 접근 권한과 VIEW · EXTRACT 확인 | 적용되는 DLP 정책의 처리 제한
- 증적(Evidence): Copilot 상호작용 감사 | DLP 활동 및 경고 [확인 필요: 정책·라이선스별 범위]
- 메뉴(Admin Center): Microsoft Purview > 정보 보호 > 레이블 [확인 필요: 현재 메뉴] | Microsoft Purview > 데이터 손실 방지
- 라이선스(License): 정보 보호·암호화 및 Copilot DLP별 요구 SKU·역할 [확인 필요]

### L3 · 0 · 기능 상태 전이 — 보호 상태 확인 → 레이블 구성 → 문서 요약

#### L4 · ⓪ 기준 — 문서의 보호와 접근 권한을 확인

1. [시작] 관리자가 테스트 문서를 선택
   - 주체: 관리자
   - 데이터: 테스트 문서 · 사용자
   - 해설: 실제 민감 데이터를 사용하지 않는 문서로 보호 상태를 살펴봅니다.
2. [처리] 문서에 적용된 민감도 레이블을 확인
   - 주체: 관리자
   - 위치: 문서의 민감도 레이블 표시
   - 데이터: 레이블 · 암호화 적용 여부
   - 해설: 레이블이 있다고 해서 모든 문서가 암호화된 것은 아닙니다.
3. [처리] 사용자에게 부여된 사용 권한을 확인
   - 주체: 관리자
   - 데이터: 파일 접근 권한 · VIEW · EXTRACT
   - 해설: 파일 접근과 암호화된 콘텐츠의 사용 권한을 구별합니다.
4. [끝] 별도 DLP 정책 적용 여부를 검토
   - 주체: 관리자
   - 데이터: 레이블 · Copilot DLP 정책
   - 해설: DLP 정책은 레이블의 암호화 권한과 별도로 적용될 수 있습니다.

#### L4 · ① 구성 — 레이블과 테스트 사용 권한 검토

1. [시작] 관리자가 테스트 보호 요구 사항을 정한다
   - 주체: 관리자
   - 위치: 조직의 정보 보호 기준
   - 데이터: 보호 대상 · 테스트 사용자
   - 해설: 대상 문서와 접근해야 하는 사용자를 먼저 정합니다.
2. [처리] 민감도 레이블 설정을 확인
   - 주체: 관리자
   - 위치: Microsoft Purview › 정보 보호 › 레이블 [확인 필요: 메뉴]
   - 데이터: 대상 레이블 · 암호화 설정
   - 해설: 해당 레이블이 암호화를 적용하는지 확인합니다.
3. [처리] 암호화된 콘텐츠의 사용 권한을 검토
   - 주체: 관리자
   - 위치: 민감도 레이블 › 암호화 설정
   - 데이터: 사용자 · VIEW · EXTRACT
   - 해설: 요약에 필요한 VIEW와 EXTRACT 사용 권한을 구분합니다.
4. [처리] 레이블을 테스트 문서에 적용
   - 주체: 사용자
   - 위치: 지원되는 Microsoft 365 앱의 민감도 메뉴
   - 데이터: 문서 · 적용 레이블
   - 해설: 테스트 문서에 검토한 레이블을 적용합니다.
5. [처리] Copilot 대상 DLP 정책을 별도로 확인
   - 주체: 관리자
   - 위치: Microsoft Purview › 데이터 손실 방지 › 정책 [확인 필요: 메뉴]
   - 데이터: 정책 위치 · 대상 사용자 · 레이블 조건
   - 해설: DLP가 적용되는 문서와 사용자, 동작을 레이블 권한과 별도로 확인합니다.
6. [끝] 테스트 환경의 역할과 라이선스를 검토
   - 주체: 관리자
   - 위치: Microsoft Purview 관리 센터
   - 데이터: 정보 보호 및 DLP 요구 역할·SKU [확인 필요]
   - 해설: 적용 환경의 라이선스와 관리 역할을 확인한 뒤 테스트합니다.

#### L4 · ② 적용 — 허용된 문서의 요약과 기록 검토

1. [시작] 사용자가 보호된 문서의 요약을 요청
   - 주체: 사용자
   - 데이터: 사용자 · 암호화 문서 · 질문
   - 해설: 사용자가 보호된 문서의 내용을 요약하도록 요청합니다.
2. [처리] 문서의 접근 가능성을 확인
   - 주체: Copilot
   - 데이터: 파일 권한 · 사용자 컨텍스트
   - 해설: 먼저 사용자가 해당 문서에 접근할 수 있어야 합니다.
3. [처리] 암호화 사용 권한을 확인
   - 주체: Copilot
   - 데이터: VIEW · EXTRACT
   - 해설: 암호화된 문서를 요약하거나 반환하려면 VIEW와 EXTRACT가 필요합니다.
4. [처리] 적용되는 별도 DLP 정책을 검토
   - 주체: Microsoft Purview
   - 데이터: 문서 레이블 · DLP 정책 [확인 필요: 정책 범위]
   - 해설: DLP가 해당 콘텐츠의 Copilot 처리를 제한할 수 있습니다.
5. [처리] 허용된 예시에서 응답을 생성
   - 주체: Copilot
   - 데이터: 허용된 문서 내용 · 응답
   - 해설: 필요한 권한과 적용 정책을 충족한 예시에서 응답이 생성됩니다.
6. [끝] 관리자가 증적을 구분해 조사
   - 주체: 관리자
   - 위치: Microsoft Purview › 감사 · 데이터 손실 방지
   - 데이터: Copilot 상호작용 · 해당 DLP 활동 [확인 필요]
   - 해설: 감사와 DLP 활동은 서로 다른 증적이며 발생 조건을 확인합니다.

> 교육 포인트: 권한이 있어도 DLP·지원되지 않는 암호화 구성 등 별도 제한이 있을 수 있습니다. 확인일 2026-11-24.

### L3 · A · 암호화 문서 처리 — VIEW와 EXTRACT, DLP를 구분

#### L4 · 보호 문서의 요약 — 사용 권한과 정책에 따른 결과

1. [시작] 사용자가 암호화된 문서의 요약을 요청
   - 주체: 사용자
   - 데이터: 문서 · 사용자 · 요청
   - 해설: 암호화된 문서를 기준으로 접근과 사용 권한을 비교합니다.
2. [판단] 사용자가 문서에 접근하고 VIEW를 보유하는가?
   - 주체: Copilot
   - 데이터: 파일 접근 권한 · VIEW
   - 해설: 접근과 보기 권한이 없다면 해당 내용을 요약할 수 없습니다.
   - 있음 → 3
   - 없음 → 8
3. [판단] 사용자가 EXTRACT 사용 권한을 보유하는가?
   - 주체: Copilot
   - 데이터: EXTRACT
   - 해설: VIEW만 있으면 요약하지 않지만 Copilot 외부에서 열 수 있는 링크를 반환할 수 있습니다.
   - 있음 → 4
   - 없음 → 9
4. [판단] 적용되는 Copilot DLP 정책이 요약을 제한하는가?
   - 주체: Microsoft Purview
   - 데이터: 정책 범위 · 레이블 조건 [확인 필요: 적용 정책]
   - 해설: 사용 권한과 별개로 DLP 정책이 레이블이 적용된 파일의 요약을 제한할 수 있습니다.
   - 제한 없음 → 5
   - 제한 → 10
5. [처리] 지원되는 문서의 내용을 사용
   - 주체: Copilot
   - 데이터: 허용된 콘텐츠
   - 해설: 암호화 구성의 별도 예외가 없을 때 해당 내용을 응답에 사용할 수 있습니다.
6. [처리] 응답과 인용을 확인
   - 주체: 사용자
   - 데이터: 응답 · 해당하는 경우 인용
   - 해설: 응답 내용과 원본을 비교합니다.
7. [끝] 상호작용 증적을 조사
   - 주체: 관리자
   - 위치: Microsoft Purview › 감사
   - 데이터: 상호작용 · 접근한 리소스
   - 해설: 감사 기록에서 접근 리소스를 조사합니다.
8. [차단] 접근 또는 VIEW 없음 — 문서 내용 미제공
   - 주체: Copilot
   - 데이터: 미허용 문서
   - 해설: 문서에 대한 접근과 보기 권한이 없는 경우 내용을 제공하지 않습니다.
9. [끝] VIEW만 있음 — 요약 제한, 링크 반환 가능
   - 주체: Copilot
   - 데이터: VIEW · EXTRACT 없음 · 링크 가능성
   - 해설: Copilot은 내용을 요약하지 않으며 링크를 반환할 수 있습니다.
10. [끝] DLP 제한 — 콘텐츠 요약 대신 링크 가능
   - 주체: Microsoft Purview
   - 데이터: DLP 정책 결과 · 경고 [확인 필요: 구성별 증적]
   - 해설: 정책이 요약을 막는 예시이며 링크 반환과 증적의 실제 조건은 별도 확인합니다.
- 시나리오: 있음 ▸ 있음 ▸ 제한 없음 :: 보기와 추출 허용으로 문서 요약
- 시나리오: 있음 ▸ 있음 ▸ 제한 :: DLP가 보호 문서의 요약 제한
- 시나리오: 있음 ▸ 없음 :: VIEW만 있어 요약 없이 링크 가능
- 시나리오: 없음 :: 접근 또는 보기 권한이 없어 미제공

> 주의: 사용자 정의 권한으로 암호화된 미개봉 문서와 DKE에는 별도 예외가 있습니다. 적용 문서·앱과 사용자 직접 참조 여부를 공식 문서와 환경에서 확인합니다.
