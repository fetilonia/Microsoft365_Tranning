## L2 · 웹 그라운딩 — 외부 웹 검색 사용 여부

- 설정(Control Plane): Cloud Policy의 Allow web search in Copilot | 사용자 Web content 선택
- 강제(Enforcement): 적용 정책과 사용자 설정 확인 | 필요 시 생성된 검색 쿼리를 Bing 검색 서비스에 전달
- 증적(Evidence): Copilot Chat 웹 검색 쿼리 인용 | Purview의 검색·감사 및 eDiscovery [확인 필요: 역할·SKU]
- 메뉴(Admin Center): Microsoft 365 Apps 관리 센터 > Cloud Policy [확인 필요: 정책 구성 메뉴]
- 라이선스(License): Copilot 또는 적격 Copilot Chat 경험 | DLP·감사·eDiscovery별 라이선스 [확인 필요]

### L3 · 0 · 기능 상태 전이 — 현재 설정 확인 → 정책 구성 → 검색 사용

#### L4 · ⓪ 기준 — 웹 검색 정책과 사용자 선택 확인

1. [시작] 관리자가 대상 사용자와 Copilot 경험을 확인
   - 주체: 관리자
   - 데이터: 사용자 · Copilot 또는 Copilot Chat
   - 해설: 이 두 경험의 웹 검색 정책과 사용자 선택을 구분합니다.
2. [처리] 관리자의 웹 검색 정책을 확인
   - 주체: 관리자
   - 위치: Microsoft 365 Apps 관리 센터 › Cloud Policy
   - 데이터: Allow web search in Copilot 정책
   - 해설: 웹 검색의 조직 정책을 확인합니다.
3. [처리] 대상 클라이언트와 지역을 검토
   - 주체: 관리자
   - 데이터: 클라이언트 · 지역 · 정책 구성 상태
   - 해설: 정책 미구성 시의 동작은 지역과 관련 설정에 따라 다를 수 있습니다.
4. [끝] 사용자 Web content 선택을 확인
   - 주체: 사용자
   - 데이터: 사용자 토글 · 관리자 정책
   - 해설: 지원되는 경험에서 사용자 선택은 관리자 정책과 별도로 확인합니다.

#### L4 · ① 구성 — 대상 사용자에게 웹 검색 정책 적용

1. [시작] 조직의 웹 검색 요구를 정한다
   - 주체: 관리자
   - 위치: 조직의 데이터 보호 기준
   - 데이터: 대상 사용자 · 웹 검색 필요 여부
   - 해설: 웹 검색을 허용할 사용자 범위와 정보 보호 요구를 검토합니다.
2. [처리] Cloud Policy 서비스를 연다
   - 주체: 관리자
   - 위치: Microsoft 365 Apps 관리 센터 › Cloud Policy
   - 데이터: 정책 구성 [확인 필요: 메뉴]
   - 해설: Microsoft 365용 Cloud Policy에서 관련 정책을 관리합니다.
3. [처리] 대상 사용자 또는 그룹을 지정
   - 주체: 관리자
   - 위치: Cloud Policy › 정책 구성 [확인 필요]
   - 데이터: 사용자 · 그룹 범위
   - 해설: 정책을 적용할 대상을 정합니다.
4. [처리] 웹 검색 허용 여부를 설정
   - 주체: 관리자
   - 위치: Cloud Policy › Allow web search in Copilot
   - 데이터: 정책 사용 또는 사용 안 함
   - 해설: 조직에서 웹 검색을 켜거나 끄는 정책을 설정합니다.
5. [처리] 정책 적용과 대상 클라이언트를 확인
   - 주체: 관리자
   - 위치: Cloud Policy › 정책 상태 [확인 필요]
   - 데이터: 대상 · 적용 결과
   - 해설: 설정 저장과 실제 사용자 적용 여부를 구분합니다.
6. [끝] 필요 시 Copilot DLP 정책을 따로 검토
   - 주체: 관리자
   - 위치: Microsoft Purview › 데이터 손실 방지 [확인 필요: 메뉴]
   - 데이터: 프롬프트 및 웹 검색 대상 규칙 [확인 필요]
   - 해설: DLP 정책은 웹 검색 설정과 별도이며 라이선스와 적용 조건을 확인합니다.

#### L4 · ② 적용 — 검색 쿼리와 결과를 확인

1. [시작] 사용자가 최신 공개 정보에 관한 질문을 입력
   - 주체: 사용자
   - 데이터: 사용자 프롬프트
   - 해설: 공개 웹 정보가 응답에 도움이 될 수 있는 질문을 입력합니다.
2. [처리] 관리 정책과 사용자 웹 설정을 확인
   - 주체: Copilot
   - 데이터: 관리자 정책 · Web content 선택
   - 해설: 웹 검색 가능 여부는 두 설정의 적용을 받습니다.
3. [처리] 필요한 경우 검색 쿼리를 생성
   - 주체: Copilot
   - 데이터: 프롬프트에서 생성된 검색어
   - 해설: 생성된 검색 쿼리는 원본 프롬프트와 구별되지만 짧은 프롬프트는 전체가 될 수도 있습니다.
4. [처리] Bing 검색 서비스에 쿼리를 전송
   - 주체: Copilot
   - 데이터: 생성된 쿼리 · 클라이언트 IP
   - 해설: 웹 검색이 사용되면 생성된 쿼리와 위치 맞춤 등에 쓰이는 클라이언트 IP가 전송됩니다.
5. [처리] 웹 결과를 응답에 활용
   - 주체: Copilot
   - 데이터: 검색 결과 · 응답 · 웹 인용
   - 해설: 검색 결과가 관련이 있으면 웹 정보를 응답의 근거로 사용할 수 있습니다.
6. [끝] 검색 쿼리와 조사 경로를 확인
   - 주체: 관리자
   - 위치: Copilot Chat 인용 또는 Microsoft Purview
   - 데이터: 웹 쿼리 인용 · 검색 가능한 기록
   - 해설: 웹 쿼리 인용은 Copilot Chat에 표시되며 앱의 Copilot 창에서는 제공되지 않습니다.

> 교육 포인트: 웹 검색이 허용돼도 모든 질문에서 검색이 발생하는 것은 아닙니다. 확인일 2026-11-24.
> 주의: 검색 쿼리는 원본 문서 전체를 포함하지 않지만 특정 앱 내 열린 문서 또는 명시적으로 참조한 문서의 정보가 쿼리에 영향을 줄 수 있습니다.

### L3 · A · 웹 검색 판단 — 관리자와 사용자 선택을 구분

#### L4 · 웹 검색이 필요한 질문 — 정책과 사용자 선택에 따른 경로

1. [시작] 사용자가 공개 웹 정보에 관한 질문을 제출
   - 주체: 사용자
   - 데이터: 질문 · 클라이언트
   - 해설: 웹 검색이 유용할 수 있는 질문을 예로 듭니다.
2. [판단] 관리자가 이 사용자에게 웹 검색을 허용했는가?
   - 주체: 관리자
   - 데이터: 적용된 Cloud Policy
   - 해설: 관리자가 웹 검색을 끄면 사용자에게 웹 검색이 제공되지 않습니다.
   - 허용 → 3
   - 차단 → 8
3. [판단] 지원되는 경험에서 사용자 웹 콘텐츠 선택이 켜져 있는가?
   - 주체: 사용자
   - 데이터: Web content 토글
   - 해설: 사용자가 웹 콘텐츠를 끄면 응답에 웹 콘텐츠가 포함되지 않습니다.
   - 켜짐 → 4
   - 꺼짐 → 9
4. [처리] Copilot이 웹 검색이 유용한지 판단
   - 주체: Copilot
   - 데이터: 프롬프트 · 검색 필요성
   - 해설: 정책과 사용자 선택이 허용해도 검색이 항상 실행되는 것은 아닙니다.
5. [처리] 검색이 필요한 예시에서 쿼리 생성 및 전송
   - 주체: Copilot
   - 데이터: 생성된 검색어 · 클라이언트 IP
   - 해설: 프롬프트에서 생성한 검색어를 Bing 검색 서비스에 보냅니다.
6. [처리] 결과를 근거로 응답
   - 주체: Copilot
   - 데이터: 웹 결과 · 응답 · 인용
   - 해설: 관련 결과가 있으면 이를 응답에 활용합니다.
7. [끝] 웹 쿼리 인용 또는 관리자 조사
   - 주체: 사용자
   - 위치: Copilot Chat › 응답 인용
   - 데이터: 생성된 검색 쿼리
   - 해설: Copilot Chat의 웹 검색 쿼리 인용은 대화에서 24시간 사용할 수 있습니다.
8. [끝] 관리자 정책 차단 — 웹 검색 미사용
   - 주체: Copilot
   - 데이터: 웹 검색 비활성 정책
   - 해설: 이 경우 웹 검색을 사용하지 않으며 다른 사용 가능한 근거의 범위는 경험에 따라 다릅니다.
9. [끝] 사용자 토글 끔 — 웹 콘텐츠 제외
   - 주체: 사용자
   - 데이터: 사용자 Web content 설정
   - 해설: 사용자 선택이 꺼져 있으면 웹 콘텐츠는 응답에 포함되지 않습니다.
- 시나리오: 허용 ▸ 켜짐 :: 웹 검색이 필요한 질문에 검색어 전송
- 시나리오: 허용 ▸ 꺼짐 :: 사용자 선택으로 웹 콘텐츠 제외
- 시나리오: 차단 :: 관리자 정책으로 웹 검색 사용 안 함

> 주의: 프롬프트 DLP의 별도 차단 조건과 증적·라이선스는 [확인 필요]. 관리 정책 미구성의 기본값은 지역에 따라 검토합니다.
