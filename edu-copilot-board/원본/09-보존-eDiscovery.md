## L2 · 보존 · eDiscovery — Copilot 대화 증적

- 설정(Control Plane): Microsoft Purview의 Copilot 경험 보존 정책 | eDiscovery 검색 및 역할
- 강제(Enforcement): 사용자 사서함의 상호작용 복사본과 보존 · 삭제 처리 | 다른 보존 또는 보류 우선
- 증적(Evidence): eDiscovery의 프롬프트·응답 검색 | 감사의 상호작용 메타데이터
- 메뉴(Admin Center): Microsoft Purview > 데이터 수명 주기 관리 > 보존 정책 [확인 필요: 메뉴] | Microsoft Purview > eDiscovery
- 라이선스(License): 보존 · eDiscovery · 감사 기능별 SKU와 역할 [확인 필요]

### L3 · 0 · 기능 상태 전이 — 저장 위치 확인 → 보존 정책 → 검색

#### L4 · ⓪ 기준 — 상호작용과 감사 기록 구별

1. [시작] 사용자가 Copilot에 질문을 보낸다
   - 주체: 사용자
   - 데이터: 프롬프트 · 응답
   - 해설: 사용자와 Copilot의 상호작용에는 질문과 응답이 포함됩니다.
2. [처리] 상호작용 데이터가 저장
   - 주체: Microsoft 365
   - 데이터: 사용자 사서함의 숨겨진 폴더에 저장된 복사본
   - 해설: 규정 준수 조사를 위한 상호작용 데이터가 사서함에 저장됩니다.
3. [처리] 감사의 활동 정보를 확인
   - 주체: 관리자
   - 위치: Microsoft Purview › 감사
   - 데이터: 사용자 · 시각 · 접근한 리소스
   - 해설: 감사 기록은 상호작용의 메타데이터를 조사합니다.
4. [끝] 프롬프트 본문과 감사 기록을 구별
   - 주체: 관리자
   - 데이터: 감사 메타데이터 · 검색 가능한 상호작용 본문
   - 해설: 감사 기록에는 프롬프트와 응답의 본문이 들어 있지 않습니다.

#### L4 · ① 구성 — Copilot 상호작용 보존 정책 검토

1. [시작] 조직의 보존 요구를 확인
   - 주체: 관리자
   - 위치: 조직의 규정 준수 기준
   - 데이터: 대상 사용자 · 보존 기간
   - 해설: 교육용 예시의 보존 대상과 기간을 정합니다.
2. [처리] Purview에서 보존 정책을 연다
   - 주체: 관리자
   - 위치: Microsoft Purview › 데이터 수명 주기 관리 › 보존 정책 [확인 필요]
   - 데이터: 정책 구성 · 관리 역할
   - 해설: 보존 정책 관리에 필요한 역할과 라이선스를 확인합니다.
3. [처리] 정책 위치를 확인
   - 주체: 관리자
   - 위치: 보존 정책 › 위치 선택 [확인 필요: 메뉴]
   - 데이터: Microsoft Copilot experiences
   - 해설: 새 정책에서 Copilot 경험의 위치를 선택하고 대상 경험을 검토합니다.
4. [처리] 대상 사용자를 정한다
   - 주체: 관리자
   - 위치: 보존 정책 › 사용자 범위 [확인 필요]
   - 데이터: 포함 · 제외 대상
   - 해설: 정책이 적용될 사용자 범위를 확인합니다.
5. [처리] 보존과 삭제 동작을 지정
   - 주체: 관리자
   - 위치: 보존 정책 › 보존 설정 [확인 필요]
   - 데이터: 보존 기간 · 보존만 또는 보존 후 삭제
   - 해설: 예시에서는 일정 기간 보존 후 삭제를 선택합니다.
6. [끝] 적용 상태와 eDiscovery 권한을 확인
   - 주체: 관리자
   - 위치: Microsoft Purview › 보존 정책 · eDiscovery
   - 데이터: 적용 상태 · 검색 역할
   - 해설: 정책 전파와 검색 권한을 별도로 확인합니다.

#### L4 · ② 적용 — 상호작용 검색과 감사 조사

1. [시작] 대상 사용자가 Copilot을 사용
   - 주체: 사용자
   - 데이터: 프롬프트 · 응답
   - 해설: 사용자 질문과 Copilot 응답이 생성됩니다.
2. [처리] 상호작용 복사본이 사용자 사서함에 저장
   - 주체: Exchange Online
   - 데이터: 숨겨진 폴더의 메시지 복사본
   - 해설: 숨겨진 폴더는 사용자나 관리자가 직접 열도록 설계되지 않았습니다.
3. [처리] 보존 정책의 범위와 기간을 적용
   - 주체: Microsoft Purview
   - 데이터: 사용자 범위 · 보존 기간 · 적용 정책
   - 해설: 사서함의 메시지에 구성된 보존 정책이 적용됩니다.
4. [처리] 규정 준수 관리자가 eDiscovery로 검색
   - 주체: 관리자
   - 위치: Microsoft Purview › eDiscovery
   - 데이터: 대상 사용자 · 기간 · 검색 조건
   - 해설: eDiscovery는 보존된 상호작용 내용을 조사하는 경로입니다.
5. [처리] 감사에서 상호작용 메타데이터 조사
   - 주체: 관리자
   - 위치: Microsoft Purview › 감사
   - 데이터: 사용자 · 시각 · 접근한 리소스
   - 해설: 감사 기록 자체에는 프롬프트와 응답의 본문이 없습니다.
6. [끝] 보존 및 삭제의 실제 상태를 판단
   - 주체: 관리자
   - 데이터: 정책 · 보류 · 검색 결과
   - 해설: 앱에 보이는 대화만으로 보존 또는 영구 삭제 상태를 판단하지 않습니다.

> 교육 포인트: 새 정책의 Copilot 경험 위치는 Teams 채팅과 별도입니다. 확인일 2026-11-24.

### L3 · A · 대화 보존과 검색 — 삭제 · 보류 · 감사 차이

#### L4 · 보존 후 삭제 정책 — 사용자 삭제와 보류 여부 비교

1. [시작] 보존 후 삭제 정책이 적용된 사용자가 Copilot을 사용
   - 주체: 사용자
   - 데이터: 프롬프트 · 응답 · 보존 기간
   - 해설: 지정 기간 보존 후 삭제하는 정책을 예로 듭니다.
2. [판단] 사용자가 보존 기간 중 대화를 제거했는가?
   - 주체: 사용자
   - 데이터: 대화 삭제 여부
   - 해설: 사용자가 앱에서 대화를 제거했는지 비교합니다.
   - 제거함 → 3
   - 유지함 → 4
3. [처리] 제거된 메시지를 보존 경로에서 유지
   - 주체: Exchange Online
   - 데이터: SubstrateHolds · 보존 기간
   - 해설: 보존 기간에 앱에서 제거된 메시지는 보존 경로에서 검색 가능합니다.
   - 다음 → 5
4. [처리] 보존 기간 동안 메시지를 유지
   - 주체: Exchange Online
   - 데이터: 사서함의 상호작용 복사본
   - 해설: 메시지가 앱에 남아 있는 예시에서 기간 만료 후의 처리를 기다립니다.
5. [판단] 다른 보존 정책이나 eDiscovery 보류가 있는가?
   - 주체: Microsoft Purview
   - 데이터: 다른 보존 정책 · Litigation Hold · eDiscovery 보류
   - 해설: 다른 보존 또는 보류가 있으면 영구 삭제가 중단될 수 있습니다.
   - 없음 → 6
   - 있음 → 9
6. [처리] 기간 만료 후 삭제 처리를 기다림
   - 주체: Exchange Online
   - 데이터: SubstrateHolds · 주기적 타이머
   - 해설: 삭제는 즉시 완료되지 않으며 숨겨진 보류 폴더와 주기적 작업을 거칩니다.
7. [처리] eDiscovery 결과와 감사 메타데이터를 구분
   - 주체: 관리자
   - 위치: Microsoft Purview › eDiscovery · 감사
   - 데이터: 검색 가능한 상호작용 본문 · 감사 활동
   - 해설: 감사 메타데이터만으로 프롬프트와 응답 본문을 볼 수 없습니다.
8. [끝] 영구 삭제 후 상호작용 검색 결과 없음
   - 주체: 관리자
   - 데이터: 삭제 완료 · eDiscovery 검색
   - 해설: 영구 삭제가 완료된 메시지는 eDiscovery 검색에 반환되지 않습니다.
9. [끝] 다른 보존 또는 보류로 영구 삭제 중단
   - 주체: 관리자
   - 데이터: 적용된 보존 정책 · 보류
   - 해설: 다른 보존이나 보류가 영향을 주는지 조사합니다.
- 시나리오: 제거함 ▸ 없음 :: 사용자가 제거해도 보존 후 삭제 처리
- 시나리오: 유지함 ▸ 없음 :: 메시지 유지 후 보존 기간 만료와 삭제
- 시나리오: 제거함 ▸ 있음 :: 사용자 제거 후 다른 보류로 삭제 중단
- 시나리오: 유지함 ▸ 있음 :: 메시지 유지 중 다른 보류로 삭제 중단

> 주의: 삭제는 주기적 처리와 최소 보류 시간 때문에 지연될 수 있으며 다른 보존·법적 보류가 우선할 수 있습니다. 검색 역할·라이선스와 실제 정책 적용은 [확인 필요].
