# Copilot · Graph 교육 보드 초안

[보드 열기](edu-copilot-board.html) · [기능별 원고](원본/) · [기존 분리본](../entra-edu-board/split/06-Copilot-Graph.md)

기존 분리 원고에서 옮긴 기능별 설정 · 강제 · 증적을 보여 줍니다. 이 원고는 검증 전 초안이며 메뉴, 라이선스, 출처와 L3/L4 시나리오는 작성되지 않았습니다. 따라서 애니메이션은 아직 제공하지 않습니다.

`원본/`의 기능별 MD를 수정한 뒤 저장소 루트에서 `python build_edu_boards.py`를 실행하면 이 보드를 포함한 네 보드가 다시 생성됩니다. 기능과 시나리오 작성 형식은 [Entra 보드 규격](../entra-edu-board/원본/00-보드-규격.md)을 참고합니다.
